    Ficheros

    Hasta ahora, los datos que hemos manejado en nuestras variables se pierden en cuanto el script termina de ejecutarse. Las sesiones nos permitieron extender la vida de esos datos durante la visita de un usuario, pero siguen siendo temporales. La persistencia de datos es la capacidad de una aplicación para guardar información de forma permanente en el disco del servidor, de manera que sobreviva entre diferentes sesiones e incluso si el servidor se reinicia.

    Antes de introducir la complejidad de un sistema de gestión de bases de datos como MySQL, es fundamental entender el método de persistencia más directo que existe: el almacenamiento en ficheros. Para aplicaciones sencillas, guardar la información en un fichero de texto puede ser una solución perfectamente válida y mucho más simple que configurar y mantener una base de datos.

    Los casos de uso típicos para la persistencia en ficheros incluyen:

    • Sistemas de comentarios o libros de visitas simples.
    • Registros de actividad (logs) para monitorizar eventos en la aplicación.
    • Almacenamiento de configuraciones sencillas.
    • Sistemas de caché para guardar temporalmente resultados de operaciones costosas.

    Para guardar datos estructurados, es común utilizar formatos estandarizados como CSV (valores separados por comas) para datos tabulares, o JSON, que es extremadamente popular por su legibilidad y por lo fácil que es convertirlo desde y hacia los arrays de PHP.

    El ciclo de vida del trabajo con ficheros en PHP se basa en tres operaciones fundamentales: abrir un fichero en un modo específico (lectura, escritura, etc.), leer o escribir su contenido, y finalmente cerrar el fichero para liberar los recursos. En las siguientes secciones, exploraremos las funciones que PHP nos proporciona para realizar estas tareas.

    Operaciones Fundamentales sobre Ficheros

    PHP, al ser un lenguaje de servidor, tiene un potente conjunto de funciones para interactuar con el sistema de ficheros del servidor. Esto nos permite crear, leer y modificar ficheros, una capacidad esencial para la persistencia de datos. Para entender cómo funciona, comenzaremos con el método de bajo nivel, que nos da un control total sobre el proceso.

    El Método Fundamental

    Este es el enfoque clásico para la manipulación de ficheros, heredado de lenguajes como C. El proceso consiste en obtener un "puntero" o "manejador" (handle) del fichero, operar a través de él y, finalmente, cerrarlo.

    Abrir el Fichero

    La función fopen() abre una conexión a un fichero y nos devuelve un recurso de tipo "puntero" que usaremos para las demás operaciones. Su argumento más importante es el modo de apertura, que le indica a PHP qué queremos hacer.

    Modo Descripción Comportamiento del Puntero/Fichero
    'r' Leer (Read) El puntero se coloca al principio. Si el fichero no existe, da error.
    'w' Escribir (Write) El puntero se coloca al principio. Si el fichero existe, su contenido se borra. Si no existe, se intenta crear.
    'a' Añadir (Append) El puntero se coloca al final. Si el fichero existe, se conserva su contenido. Si no existe, se intenta crear.
    'r+' Lectura y Escritura El puntero se coloca al principio.
    'w+' Lectura y Escritura Igual que 'w', borra el contenido del fichero si existe.
    'a+' Lectura y Escritura/Añadir El puntero se coloca al final para escribir, pero se puede mover para leer.

    Escribir y Cerrar

    Una vez abierto un fichero en modo de escritura ('w') o añadir ('a'), usamos fwrite() para escribir en él. Es crucial cerrar siempre el fichero con fclose() para liberar los recursos del sistema.

    Ejemplo de escritura: 

    <?php
    $fichero = 'notas.txt';
    $puntero = fopen($fichero, 'w'); // Abrir en modo escritura (borra el contenido anterior)

    if ($puntero) {
        fwrite($puntero, "Esta es la primera línea.\n");
        fwrite($puntero, "Esta es la segunda línea.\n");

        fclose($puntero); // ¡Importante cerrar el fichero!
        echo "Se ha escrito en el fichero 'notas.txt'.";
    } else {
        echo "No se pudo abrir el fichero para escribir.";
    }
?>

    Leer y Cerrar

    Para leer, abrimos el fichero en modo lectura ('r'). Aunque fread() lee un número específico de bytes, es mucho más común leer un fichero línea por línea. Para ello, se usa la función fgets() (que lee una línea) dentro de un bucle while que comprueba el fin de fichero con feof().

    <?php
    $fichero = 'notas.txt';
    $puntero = fopen($fichero, 'r'); // Abrir en modo solo lectura

    if ($puntero) {
        echo "<h2>Contenido de 'notas.txt':</h2>";
        // Mientras no lleguemos al final del fichero (End-Of-File)...
        while (!feof($puntero)) {
            // ...leemos la siguiente línea y la mostramos.
            $linea = fgets($puntero);
            echo $linea . "<br>";
        }

        fclose($puntero); // Cerramos el fichero al terminar.
    } else {
        echo "No se pudo abrir el fichero para leer.";
    }
?>

    Funciones "Todo en Uno"

    Ahora que entendemos el proceso completo, podemos apreciar las funciones de alto nivel que PHP nos ofrece como atajos. Estas funciones realizan el ciclo de fopen/operación/fclose por nosotros en una sola llamada.

    • file_put_contents($fichero, $datos, [flags]): Es el equivalente a fopen en modo 'w', fwrite y fclose. Si se usa la bandera FILE_APPEND, equivale a abrir en modo 'a'. Es la forma moderna y segura de escribir ficheros.
    • file_get_contents($fichero): Es el equivalente a fopen en modo 'r', leer todo el contenido de una vez y fclose. Ideal para leer ficheros que no son excesivamente grandes.

    Independientemente del método que uses, es una buena práctica comprobar el estado del fichero antes de operar sobre él para evitar errores.

    • file_exists($ruta): Devuelve true si el fichero o directorio existe.
    • is_readable($ruta): Devuelve true si el fichero existe y se puede leer.
    • is_writable($ruta): Devuelve true si el fichero existe y se puede escribir en él.
    <?php
    $fichero = 'config.json';

    if (file_exists($fichero) && is_readable($fichero)) {
        $config_json = file_get_contents($fichero);
        // ... procesar el JSON ...
    } else {
        die("Error: El fichero de configuración no existe o no se puede leer.");
    }
?>

    Leyendo Ficheros XML con SimpleXML

    A menudo, no guardaremos datos en ficheros de texto plano sin formato, sino en formatos estructurados que nos permitan representar relaciones complejas de una manera estándar. Uno de los formatos más clásicos para el intercambio de datos es XML (eXtensible Markup Language).

    XML organiza los datos de forma jerárquica mediante etiquetas, de forma similar a HTML, pero con la diferencia de que las etiquetas no están predefinidas, sino que las creamos nosotros para describir nuestros datos.

    PHP ofrece varias formas de trabajar con XML, pero la más sencilla e intuitiva es la extensión SimpleXML. Esta herramienta nos permite convertir un documento XML en un objeto de PHP, que podemos navegar de una forma muy natural para acceder a sus datos.

    Imaginemos que tenemos el siguiente fichero, llamado libros.xml:

    <?xml version="1.0" encoding="UTF-8"?>
<catalogo>
    <libro id="bk101">
        <autor>Gambardella, Matthew</autor>
        <titulo>XML Developer's Guide</titulo>
        <genero>Computer</genero>
        <precio>44.95</precio>
    </libro>
    <libro id="bk102">
        <autor>Ralls, Kim</autor>
        <titulo>Midnight Rain</titulo>
        <genero>Fantasy</genero>
        <precio>5.95</precio>
    </libro>
    <libro id="bk103">
        <autor>Thurman, Paula</autor>
        <titulo>Maeve Ascendant</titulo>
        <genero>Fantasy</genero>
        <precio>5.95</precio>
    </libro>
</catalogo>

    Ahora, crearemos un script de PHP para leer este fichero y mostrar sus datos.

    <?php
    $fichero_xml = 'libros.xml';

    if (file_exists($fichero_xml)) {
        // 1. Cargamos el fichero XML. Esto devuelve un objeto SimpleXMLElement.
        $xml = simplexml_load_file($fichero_xml);

        if ($xml === false) {
            die("Error: No se ha podido cargar el fichero XML.");
        }

        // --- Acceso a los datos ---

        echo "<h1>Catálogo de Libros</h1>";

        // 2. Recorremos los elementos <libro> como si fuera un array.
        foreach ($xml->libro as $libro) {
            // 3. Accedemos a los atributos con una sintaxis de array.
            $id = $libro['id'];

            // 4. Accedemos a los elementos hijos como si fueran propiedades del objeto.
            $titulo = $libro->titulo;
            $autor = $libro->autor;
            $genero = $libro->genero;
            $precio = $libro->precio;

            // Mostramos la información
            echo "<div>";
            echo "<h3>" . $titulo . " (ID: " . $id . ")</h3>";
            echo "<ul>";
            echo "<li><strong>Autor:</strong> " . $autor . "</li>";
            echo "<li><strong>Género:</strong> " . $genero . "</li>";
            echo "<li><strong>Precio:</strong> $" . $precio . "</li>";
            echo "</ul>";
            echo "</div><hr>";
        }

    } else {
        die("Error: El fichero libros.xml no ha sido encontrado.");
    }
?>

    El proceso de SimpleXML se puede entender en dos fases clave. La primera es la carga del fichero, gestionada por completo por la función simplexml_load_file(). Esta función se encarga del trabajo pesado de leer el documento, verificar que su sintaxis XML es válida y, si todo es correcto, transformar toda la estructura jerárquica en un objeto especial de PHP. En caso de que el fichero esté mal formado o no sea accesible, la función devolverá false, permitiéndonos controlar el error de forma elegante.

    Una vez que la carga ha sido exitosa, comienza la fase de navegación del objeto, que es donde reside la verdadera potencia y simplicidad de la herramienta. SimpleXML nos presenta el árbol de datos como un objeto PHP con una sintaxis híbrida e intuitiva. Para acceder a los elementos hijos directos, se utiliza la notación de flecha estándar de los objetos, como en $xml->libro. Si existen múltiples elementos con el mismo nombre, como es el caso de las etiquetas <libro>, SimpleXML los agrupa de forma transparente en una colección que puede ser recorrida con un simple bucle foreach. Los atributos de una etiqueta se hacen accesibles mediante una sintaxis de array asociativo, como en $libro['id'], mientras que los elementos anidados más profundos se alcanzan encadenando el acceso a propiedades, como en $libro->titulo. De esta manera, SimpleXML abstrae la complejidad del análisis de XML y convierte la tarea en un proceso tan natural como la manipulación de objetos y arrays nativos de PHP.

    Escribiendo XML con SimpleXML

    Además de leer ficheros XML, SimpleXML también nos permite crear y guardar nuevos documentos XML desde PHP de forma sencilla. Podemos construir una estructura jerárquica desde cero y luego guardarla en disco con el método asXML().

    Imaginemos que queremos crear un fichero alumnos.xml con una lista de estudiantes y sus notas. Podemos hacerlo así:

    <?php
// 1. Creamos el nodo raíz
$xml = new SimpleXMLElement('<alumnos></alumnos>');

// 2. Añadimos nodos hijo
$alumno1 = $xml->addChild('alumno');
$alumno1->addAttribute('id', 'A001');
$alumno1->addChild('nombre', 'Laura Pérez');
$alumno1->addChild('nota', '8.5');

$alumno2 = $xml->addChild('alumno');
$alumno2->addAttribute('id', 'A002');
$alumno2->addChild('nombre', 'Carlos Ruiz');
$alumno2->addChild('nota', '9.2');

// 3. Guardamos el documento en un fichero
$xml->asXML('alumnos.xml');

echo "El archivo alumnos.xml se ha creado correctamente.";
?>

    Este script genera automáticamente un archivo con el siguiente contenido:

    <?xml version="1.0"?>
<alumnos>
    <alumno id="A001">
        <nombre>Laura Pérez</nombre>
        <nota>8.5</nota>
    </alumno>
    <alumno id="A002">
        <nombre>Carlos Ruiz</nombre>
        <nota>9.2</nota>
    </alumno>
</alumnos>

    El método addChild() sirve para añadir un nuevo elemento hijo dentro del nodo actual, mientras que addAttribute() añade atributos al elemento.
    Finalmente, asXML() puede recibir un nombre de fichero como parámetro para guardar el XML en disco, o usarse sin argumentos para devolverlo como cadena.

    Leyendo Ficheros JSON

    JSON (JavaScript Object Notation) es un formato de texto ligero para el intercambio de datos. Aunque nació del lenguaje JavaScript, hoy en día es un estándar universal, legible por humanos y fácil de procesar para las máquinas. En el desarrollo web moderno, ha reemplazado en gran medida a XML como el formato preferido para las APIs y los ficheros de configuración por ser menos verboso y más fácil de mapear a las estructuras de datos nativas de los lenguajes de programación.

    La relación entre PHP y JSON es especialmente fluida, ya que la estructura de los arrays asociativos e indexados de PHP se corresponde casi perfectamente con los objetos y arrays de JSON. PHP nos proporciona dos funciones principales para trabajar con este formato: json_encode() y json_decode().

    La función json_encode() toma una variable de PHP (generalmente un array o un objeto) y la convierte en una cadena de texto con formato JSON.

    <?php
    // Un array asociativo en PHP
    $usuario = [
        'id' => 1,
        'nombre' => 'Ana García',
        'email' => 'ana.garcia@email.com',
        'activo' => true
    ];

    // Lo convertimos a una cadena JSON
    // JSON_PRETTY_PRINT es una constante opcional que formatea el JSON para que sea legible.
    $usuario_json = json_encode($usuario, JSON_PRETTY_PRINT);

    echo "<pre>"; // Usamos <pre> para respetar los saltos de línea y espacios del JSON formateado
    echo $usuario_json;
    echo "</pre>";
?>

    Este código genera la siguiente salida:

    {
    "id": 1,
    "nombre": "Ana Garc\u00eda",
    "email": "ana.garcia@email.com",
    "activo": true
}

    Nota

    json_encode convierte los caracteres especiales como la 'í' a su representación Unicode (\u00eda).

    Por su parte, json_decode() toma una cadena de texto con formato JSON y la convierte en una variable de PHP.

    Esta función tiene un segundo argumento muy importante. Por defecto, convierte los objetos JSON en objetos stdClass de PHP. Si le pasamos true como segundo argumento, los convertirá en arrays asociativos, que suelen ser más fáciles de manejar.

    <?php
    $json_string = '{ "id": 1, "nombre": "Ana García", "activo": true }';

    // 1. Decodificando como objeto (comportamiento por defecto)
    $usuario_objeto = json_decode($json_string);
    echo "Acceso como objeto: " . $usuario_objeto->nombre; // Salida: Ana García
    echo "<br>";

    // 2. Decodificando como array asociativo (recomendado)
    $usuario_array = json_decode($json_string, true);
    echo "Acceso como array: " . $usuario_array['nombre']; // Salida: Ana García
?>

    Ejemplo Práctico: Guardar y Leer un Fichero JSON

    Ahora combinemos estas funciones con las operaciones de ficheros que ya conocemos para crear un pequeño sistema de persistencia. Primero vamos a guardar los datos en un fichero JSON:

    <?php
    // Partimos de un array multidimensional de usuarios en PHP
    $usuarios = [
        [ 'id' => 1, 'nombre' => 'Ana García' ],
        [ 'id' => 2, 'nombre' => 'Luis Soler' ]
    ];

    // Convertimos el array a una cadena JSON formateada
    $json_para_guardar = json_encode($usuarios, JSON_PRETTY_PRINT);

    // Guardamos la cadena en un fichero
    file_put_contents('usuarios.json', $json_para_guardar);

    echo "Los datos de los usuarios han sido guardados en 'usuarios.json'";
?>

    Una vez creado el fichero, podemos leerlo con la siguiente funcionalidad:

    <?php
    $fichero_json = 'usuarios.json';

    if (file_exists($fichero_json)) {
        // Leemos el contenido del fichero
        $json_string = file_get_contents($fichero_json);

        // Decodificamos el JSON a un array de PHP
        $usuarios = json_decode($json_string, true);

        echo "<h1>Lista de Usuarios</h1>";
        echo "<ul>";
        foreach ($usuarios as $usuario) {
            echo "<li>" . $usuario['nombre'] . " (ID: " . $usuario['id'] . ")</li>";
        }
        echo "</ul>";
    } else {
        echo "El fichero no existe.";
    }
?>

    Este ciclo de leer un fichero, decodificarlo, manipular el array y volver a codificarlo y guardarlo es la base de muchas aplicaciones sencillas que usan el sistema de ficheros como base de datos.

    Leyendo Ficheros CSV

    CSV (Comma-Separated Values o Valores Separados por Comas) es un formato de fichero de texto plano que se utiliza para almacenar datos en una estructura de tabla. Cada línea del fichero representa una fila de la tabla, y las columnas dentro de esa fila se separan por un delimitador, que comúnmente es una coma (,), aunque también puede ser un punto y coma (;) u otro carácter.

    La gran ventaja del formato CSV es su simplicidad y universalidad. Prácticamente cualquier software de hoja de cálculo, como Microsoft Excel o Google Sheets, puede abrir e importar datos desde un fichero CSV. Esto lo convierte en el formato ideal para funcionalidades de importación y exportación de datos en una aplicación web.

    Aunque podríamos intentar procesar un CSV con funciones de strings como explode(), es una mala idea porque no maneja casos complejos (por ejemplo, cuando una de las columnas contiene una coma). PHP ofrece funciones nativas y robustas para trabajar con CSV de forma correcta: fputcsv() y fgetcsv().

    La función fputcsv() formatea un array como una línea de CSV y la escribe en un fichero. Esta función trabaja con un "puntero" de fichero, por lo que necesitamos usar el ciclo fopen() -> fputcsv() -> fclose().

    <?php
    // Datos de ejemplo (un array de arrays)
    $productos = [
        [1, "Portátil T-1000", 899.99],
        [2, "Ratón Óptico Pro", 24.50],
        [3, "Teclado Mecánico RGB, Modelo K-7", 119.95]
    ];

    // Abrimos el fichero en modo escritura ('w')
    $puntero = fopen('productos.csv', 'w');

    // (Opcional, pero buena práctica) Escribimos una fila de cabecera
    $cabecera = ['ID', 'Nombre del Producto', 'Precio'];
    fputcsv($puntero, $cabecera);

    // Recorremos el array de productos y escribimos cada uno como una fila en el CSV
    foreach ($productos as $producto) {
        fputcsv($puntero, $producto);
    }

    // Cerramos el fichero
    fclose($puntero);

    echo "Fichero 'productos.csv' creado con éxito.";
?>

    Si abres el fichero productos.csv generado, verás un contenido como este:

    ID,"Nombre del Producto",Precio
1,"Portátil T-1000",899.99
2,"Ratón Óptico Pro",24.5
3,"Teclado Mecánico RGB, Modelo K-7",119.95

    De forma análoga, la función fgetcsv() lee una línea de un fichero CSV abierto y la convierte en un array indexado. La forma más común de usarla es dentro de un bucle while para leer el fichero entero, fila por fila.

    <?php
    $fichero_csv = 'productos.csv';

    echo "<h1>Lista de Productos desde CSV</h1>";
    echo "<table border='1' cellpadding='5'>";

    // Abrimos el fichero en modo lectura ('r')
    if (($puntero = fopen($fichero_csv, 'r')) !== false) {

        // (Opcional) Leemos la primera fila para descartar la cabecera
        $cabecera = fgetcsv($puntero);
        echo "<tr><th>" . implode("</th><th>", $cabecera) . "</th></tr>";

        // Mientras haya líneas por leer, fgetcsv() las devolverá como un array
        while (($fila = fgetcsv($puntero)) !== false) {
            echo "<tr>";
            echo "<td>" . $fila[0] . "</td>"; // ID
            echo "<td>" . $fila[1] . "</td>"; // Nombre
            echo "<td>" . $fila[2] . "</td>"; // Precio
            echo "</tr>";
        }

        // Cerramos el fichero
        fclose($puntero);
    }

    echo "</table>";
?>

    Este método es muy eficiente en el uso de memoria, ya que procesa el fichero línea por línea en lugar de cargarlo todo de golpe, lo que lo hace ideal incluso para ficheros CSV de gran tamaño.
