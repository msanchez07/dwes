    Ejercicios persistencia

    Ejercicios de Tratamiento de Ficheros en PHP

    1. Leer un archivo de texto

    Crea un script (leer_archivo.php) que abra un archivo de texto llamado mensaje.txt y muestre su contenido en pantalla.

    2. Escribir en un archivo

    Crea un script (escribir_archivo.php) que escriba la frase "Hola mundo desde PHP" dentro del archivo saludo.txt.

    3. Añadir texto a un archivo

    Crea un script (anadir_texto.php) que añada una línea con la fecha actual al final de log.txt.

    4. Comprobar si un archivo existe

    Crea un script (comprobar_archivo.php) que verifique si existe datos.txt y muestre un mensaje indicando si está presente o no.

    5. Crear un archivo si no existe

    Crea un script (crear_si_no_existe.php) que cree el archivo nuevo.txt solo si no existe previamente.

    6. Contar líneas de un archivo

    Crea un script (contar_lineas.php) que cuente cuántas líneas tiene texto.txt.

    7. Leer línea a línea

    Crea un script (leer_lineas.php) que lea un archivo línea por línea y muestre cada línea numerada.

    8. Borrar un archivo

    Crea un script (borrar_archivo.php) que elimine temporal.txt si existe.

    9. Obtener el tamaño de un archivo

    Crea un script (tamano_archivo.php) que muestre el tamaño en bytes de info.txt.

    10. Mostrar fecha de modificación

    Crea un script (fecha_modificacion.php) que muestre la fecha y hora de la última modificación de documento.txt.

    11. Copiar un archivo

    Crea un script (copiar_archivo.php) que copie original.txt a copia.txt.

    12. Mover o renombrar un archivo

    Crea un script (mover_archivo.php) que renombre temporal.txt a definitivo.txt.

    13. Leer un archivo CSV simple

    Crea un script (leer_csv.php) que lea personas.csv y muestre cada fila separada por comas.

    14. Escribir en un archivo CSV

    Crea un script (escribir_csv.php) que agregue una nueva línea con nombre y edad al archivo usuarios.csv.

    15. Leer un archivo JSON

    Crea un script (leer_json.php) que lea datos.json, lo decodifique con json_decode() y muestre sus datos.

    16. Escribir un archivo JSON

    Crea un script (escribir_json.php) que guarde un arreglo asociativo con claves nombre y edad en un archivo usuario.json.

    17. Leer un archivo XML

    Crea un script (leer_xml.php) que lea libros.xml usando simplexml_load_file() y muestre los títulos de los libros.

    18. Crear un archivo XML

    Crea un script (crear_xml.php) que genere un archivo alumnos.xml con 3 nodos <alumno> que tengan nombre y edad.

    19. Mostrar lista de archivos de una carpeta

    Crea un script (listar_archivos.php) que muestre todos los nombres de archivo dentro del directorio uploads/.

    20. Crear un archivo con datos del formulario

    Crea un formulario que solicite nombre y edad, y al enviarlo guarde esos datos en usuarios.txt usando fwrite().

    21. Buscar texto en un archivo

    Crea un script (buscar_texto.php) que pida una palabra y busque si aparece dentro de texto.txt.

    22. Reemplazar texto en un archivo

    Crea un script (reemplazar_texto.php) que reemplace todas las apariciones de una palabra en documento.txt.

    23. Leer archivo CSV y mostrar como tabla HTML

    Crea un script (csv_a_tabla.php) que lea productos.csv y muestre su contenido en una tabla HTML.

    24. Convertir JSON a CSV

    Crea un script (json_a_csv.php) que lea datos.json y genere un archivo datos.csv equivalente.

    25. Convertir CSV a JSON

    Crea un script (csv_a_json.php) que lea usuarios.csv y genere un archivo usuarios.json con los mismos datos.

    26. Fusionar dos archivos de texto

    Crea un script (fusionar_textos.php) que combine el contenido de parte1.txt y parte2.txt en final.txt.

    27. Dividir un archivo grande en partes pequeñas

    Crea un script (dividir_archivo.php) que divida un archivo grande.txt en fragmentos de 100 líneas cada uno.

    28. Crear un log de errores

    Crea un script (registro_errores.php) que guarde cada error producido por el usuario en un archivo errores.log con fecha y hora.

    29. Generar un archivo de backup

    Crea un script (backup.php) que copie todos los archivos .txt del directorio datos/ a una carpeta backup/.

    30. Contar palabras en un archivo

    Crea un script (contar_palabras.php) que cuente cuántas palabras hay en documento.txt.

    31. Validar y cargar un archivo subido

    Crea un script (subida_archivo.php) que permita subir un archivo de texto, lo valide (tamaño y tipo) y lo guarde en uploads/.

    32. Crear índice de palabras de un archivo

    Crea un script (indice_palabras.php) que lea un texto y cree un índice alfabético con cada palabra y su número de línea.

    33. Buscar en archivos múltiples

    Crea un script (buscar_en_varios.php) que busque una palabra en todos los archivos .txt de una carpeta y muestre en cuáles aparece.

    34. Comparar dos archivos línea por línea

    Crea un script (comparar_archivos.php) que compare archivo1.txt y archivo2.txt y muestre las líneas que difieren.

    35. Analizar un log CSV

    Crea un script (analizar_log.php) que lea accesos.csv y calcule cuántas veces se repite cada usuario.

    36. Generar un archivo resumen

    Crea un script (resumen.php) que lea varios archivos de texto en entradas/ y cree un resumen.txt con los totales de líneas y palabras.

    37. Editar un nodo XML

    Crea un script (editar_xml.php) que lea alumnos.xml, modifique la edad de un alumno y vuelva a guardar el archivo.

    38. Combinar varios archivos JSON

    Crea un script (combinar_json.php) que lea varios archivos .json de una carpeta y cree uno solo con todos los datos combinados.

    39. Generar un archivo CSV desde una base de datos

    Crea un script (db_a_csv.php) que lea los registros de una tabla usuarios y los exporte a usuarios.csv.

    40. Importar un archivo CSV a base de datos

    Crea un script (csv_a_db.php) que lea productos.csv e inserte sus datos en una tabla productos de MySQL.

    41. Sincronizar archivos JSON entre carpetas

    Crea un script (sincronizar_json.php) que compare los archivos JSON de carpetaA/ y carpetaB/, copiando los que falten en cada una.

    42. Crear un parser de logs

    Crea un script (parser_logs.php) que lea un archivo server.log, identifique los errores (líneas con "ERROR") y cree un resumen en errores.json.

    43. Generar un XML desde múltiples CSV

    Crea un script (csv_a_xml.php) que lea todos los CSV de data/ y genere un único archivo consolidado.xml.

    44. Monitorear cambios en un archivo

    Crea un script (monitorear_cambios.php) que detecte si config.txt cambia cada cierto tiempo y registre las diferencias en historial.txt.

    45. Crear un mini visor de archivos

    Crea un script (visor_archivos.php) que permita al usuario elegir un archivo de texto y mostrar su contenido con formato HTML.

    46. Generar informe JSON de una carpeta

    Crea un script (informe_carpetas.php) que analice todos los archivos de una carpeta (nombre, tamaño, fecha) y guarde los datos en informe.json.

    47. Convertir XML a JSON y viceversa

    Crea un script (xml_json.php) que convierta un archivo datos.xml a datos.json, y también permita el proceso inverso.

    48. Cifrar y descifrar archivos de texto

    Crea un script (cifrar_archivo.php) que guarde un archivo de texto cifrado con una clave y otro que lo descifre.

    49. Crear un sistema de versionado de archivos

    Crea un script (versionado.php) que guarde cada modificación de documento.txt con un número de versión y permita restaurar versiones anteriores.

    50. Procesar archivos grandes en streaming

    Crea un script (procesar_stream.php) que lea un archivo de texto muy grande sin cargarlo completamente en memoria, procesando línea por línea.

    Ejercicios de Conexión y Gestión de Bases de Datos en PHP

    1. Conexión simple a MySQL

    Crea un script (conexion_mysql.php) que se conecte a una base de datos MySQL llamada empresa y muestre un mensaje si la conexión fue exitosa.

    2. Conexión simple a SQLite

    Crea un script (conexion_sqlite.php) que se conecte a una base de datos datos.sqlite y muestre un mensaje de éxito.

    3. Conexión simple a MongoDB

    Crea un script (conexion_mongodb.php) que se conecte a una base de datos llamada tienda en MongoDB y muestre un mensaje si la conexión fue correcta.

    4. Crear tabla en MySQL

    Crea un script (crear_tabla_mysql.php) que cree una tabla usuarios con campos id, nombre y email en MySQL.

    5. Insertar un registro en MySQL

    Crea un script (insertar_mysql.php) que inserte un nuevo usuario en la tabla usuarios con valores fijos.

    6. Insertar un registro en SQLite

    Crea un script (insertar_sqlite.php) que agregue un registro a una tabla productos en datos.sqlite.

    7. Insertar documento en MongoDB

    Crea un script (insertar_mongodb.php) que agregue un documento {nombre, precio} a la colección productos.

    8. Leer registros de MySQL

    Crea un script (leer_mysql.php) que muestre todos los usuarios de la tabla usuarios.

    9. Leer registros de SQLite

    Crea un script (leer_sqlite.php) que lea todos los registros de la tabla clientes en clientes.sqlite.

    10. Leer documentos de MongoDB

    Crea un script (leer_mongodb.php) que lea y muestre todos los documentos de la colección clientes.

    11. Insertar datos desde formulario en MySQL

    Crea un formulario con nombre y email, y guarda los datos en la tabla usuarios usando mysqli.

    12. Mostrar resultados en tabla HTML (MySQL)

    Crea un script (tabla_mysql.php) que muestre todos los usuarios en una tabla HTML.

    13. Mostrar resultados en tabla HTML (SQLite)

    Crea un script (tabla_sqlite.php) que muestre los productos almacenados en productos.sqlite en formato HTML.

    14. Filtrar resultados por nombre (MySQL)

    Crea un script (buscar_mysql.php) que reciba un nombre por GET y muestre los usuarios que coincidan parcialmente.

    15. Actualizar un registro en MySQL

    Crea un script (actualizar_mysql.php) que cambie el email de un usuario con un determinado id.

    16. Eliminar un registro en MySQL

    Crea un script (eliminar_mysql.php) que elimine un usuario por su id.

    17. Actualizar un documento en MongoDB

    Crea un script (actualizar_mongodb.php) que modifique el precio de un producto dado su nombre.

    18. Eliminar un documento en MongoDB

    Crea un script (eliminar_mongodb.php) que elimine un documento por su nombre en la colección clientes.

    19. Crear base de datos SQLite si no existe

    Crea un script (crear_sqlite.php) que cree la base de datos inventario.sqlite si no existe, y añada una tabla articulos.

    20. Conexión MySQL con PDO

    Crea un script (conexion_pdo.php) que conecte a MySQL usando PDO y maneje excepciones de conexión.

    21. Uso de consultas preparadas (MySQL)

    Crea un script (consulta_preparada.php) que use prepare() y bind_param() para insertar usuarios de forma segura.

    22. Consultas preparadas con PDO (MySQL)

    Crea un script (pdo_prepared.php) que inserte un nuevo producto usando sentencias preparadas con PDO.

    23. Consultas preparadas con SQLite

    Crea un script (sqlite_prepared.php) que inserte y lea datos de forma segura mediante prepare().

    24. Validar conexión y manejo de errores

    Crea un script (conexion_segura.php) que maneje posibles errores de conexión y muestre mensajes personalizados.

    25. Insertar múltiples filas (MySQL)

    Crea un script (insertar_multiple.php) que inserte varios usuarios en una sola ejecución.

    26. Mostrar conteo de registros (MySQL)

    Crea un script (contar_mysql.php) que muestre cuántos usuarios hay en la tabla usuarios.

    27. Exportar datos MySQL a CSV

    Crea un script (exportar_csv.php) que lea los usuarios y genere un archivo usuarios.csv.

    28. Exportar datos SQLite a JSON

    Crea un script (sqlite_a_json.php) que lea todos los productos y los guarde en productos.json.

    29. Importar datos JSON a MongoDB

    Crea un script (importar_mongodb.php) que lea clientes.json e inserte todos los documentos en la colección clientes.

    30. Buscar registros con filtro en MongoDB

    Crea un script (filtro_mongodb.php) que busque todos los productos con precio mayor a 50.

    31. CRUD completo con MySQL

    Crea una pequeña aplicación (crud_mysql/) con páginas para crear, leer, actualizar y eliminar usuarios.

    32. CRUD completo con SQLite

    Crea una aplicación (crud_sqlite/) con las mismas operaciones pero usando SQLite.

    33. CRUD completo con MongoDB

    Crea una aplicación (crud_mongodb/) con formularios para insertar, editar y eliminar documentos.

    34. Paginación de resultados (MySQL)

    Crea un script (paginacion_mysql.php) que muestre los usuarios en páginas de 10 en 10.

    35. Búsqueda avanzada (MySQL)

    Crea un script (busqueda_avanzada.php) que permita filtrar usuarios por nombre, edad o ciudad con múltiples campos de búsqueda.

    36. Conexión a múltiples bases de datos

    Crea un script (multi_conexion.php) que se conecte tanto a MySQL como a SQLite y muestre datos combinados.

    37. Transacciones en MySQL

    Crea un script (transacciones.php) que realice varias operaciones dentro de una transacción y use commit() o rollback() según corresponda.

    38. Integración MySQL + MongoDB

    Crea un script (integracion_mysql_mongo.php) que lea productos desde MySQL y los guarde como documentos en MongoDB.

    39. Registro de logs en base de datos

    Crea un script (registro_logs.php) que guarde cada acceso del usuario (fecha, IP, acción) en una tabla MySQL.

    40. Exportar MySQL a SQLite

    Crea un script (mysql_a_sqlite.php) que lea todos los registros de una tabla MySQL y los copie a una tabla SQLite.

    41. Sistema de autenticación con MySQL

    Crea una aplicación (login_mysql/) con registro, inicio de sesión y cierre de sesión de usuarios.

    42. Sistema de autenticación con SQLite

    Crea una aplicación (login_sqlite/) similar pero usando SQLite.

    43. Indexación y búsqueda eficiente en MongoDB

    Crea un script (indices_mongo.php) que cree un índice en el campo nombre y realice búsquedas rápidas.

    44. Sincronizar datos entre MySQL y MongoDB

    Crea un script (sync_mysql_mongo.php) que compare registros y sincronice los nuevos entre ambas bases.

    45. Generar reportes en PDF desde MySQL

    Crea un script (reporte_pdf.php) que genere un PDF con los usuarios de la base de datos MySQL.

    46. Importar CSV a SQLite

    Crea un script (csv_a_sqlite.php) que lea productos.csv e inserte sus datos en una tabla SQLite.

    47. Automatizar backups de bases de datos

    Crea un script (backup_bases.php) que cree copias automáticas de todas las bases de datos (MySQL, SQLite y MongoDB).

    48. Sistema de logs distribuidos con MongoDB

    Crea un script (logs_mongodb.php) que almacene eventos de distintas aplicaciones en una única colección centralizada.

    49. Cifrar datos en base de datos

    Crea un script (cifrado_datos.php) que guarde contraseñas cifradas con password_hash() y verifique su validez.

    50. API REST con MySQL y MongoDB

    Crea una API (api_datos.php) que permita consultar, insertar y actualizar datos combinando MySQL y MongoDB como fuentes de información.
