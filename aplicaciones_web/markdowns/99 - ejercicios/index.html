    Ejercicios Prácticos: Formularios y Validación

    Los siguientes ejercicios están diseñados para aplicar los conocimientos de formularios HTML, la recepción de datos con PHP ($_GET, $_POST, $_FILES), código embebido, y validación estructurada.

    1. Saludo Simple con GET

    Crea un único archivo (saludo_get.php) con un formulario que solicite el nombre al usuario. Usa method="get". Al enviar, el script debe mostrar un saludo (¡Hola, [Nombre]!) utilizando $_GET y aplicando htmlspecialchars() al nombre.

    2. Calculadora de Suma con POST

    Crea un archivo (calculadora.php) con un formulario que solicite dos números. Usa method="post". El script debe autoprocesarse, sumar los dos números y mostrar el resultado. No utilices validación.

    3. Detección de Envío

    Crea un formulario simple con un solo campo. El script debe autoprocesarse. Utiliza $_SERVER['REQUEST_METHOD'] para determinar si la página ha sido accedida por primera vez (GET) o si el formulario ha sido enviado (POST). Muestra un mensaje diferente en cada caso.

    4. Verificación de Campos Requeridos

    Crea un formulario de registro con campos para nombre, email y mensaje. El script debe verificar que ninguno de los tres campos esté vacío. Si alguno lo está, muestra un mensaje de error. Si todos están llenos, muestra un mensaje de éxito.

    5. Suma con Conversión Explícita

    Modifica el ejercicio de la calculadora para asegurar que los valores recibidos de $_POST sean tratados como números enteros antes de la suma. Utiliza la función intval() o el type casting (int).

    6. Procesamiento de Checkbox

    Crea un formulario con un checkbox llamado acepto_terminos. El script de procesamiento debe verificar si el checkbox ha sido marcado. Recuerda que un checkbox solo aparece en $_POST si está marcado.

    7. Retención Básica de Valor

    Crea un formulario con un campo de texto para un "Asunto". Al procesar el formulario con POST, asegúrate de que, si el formulario se vuelve a mostrar, el campo de "Asunto" mantenga el último valor ingresado por el usuario, utilizando código PHP embebido en el atributo value.

    8. Validación de Email con filter_var

    Crea un formulario con un campo de email. El script debe verificar si el campo está lleno y, si lo está, utilizar filter_var($email, FILTER_VALIDATE_EMAIL) para verificar que el formato del correo electrónico sea válido. Muestra un mensaje de error específico si el formato es incorrecto.

    9. Procesamiento de Lista de Opciones (<select>)

    Crea un formulario con un desplegable de selección (<select>) con al menos tres opciones de países. El script debe procesar el formulario y mostrar el nombre del país seleccionado, asegurándose de aplicar htmlspecialchars() al valor.

    10. Subida de Archivo: Detección y Error

    Crea un formulario para subir un fichero. El script debe comprobar si el array $_FILES['nombre_del_campo'] existe. Si existe, debe verificar si hubo un error en la subida utilizando $_FILES['...']['error'] === UPLOAD_ERR_OK y mostrar un mensaje de éxito o el código de error.

    11. Prevención de XSS en el Saludo

    Modifica el ejercicio 1 para permitir un ataque XSS (por ejemplo, introduciendo <script>alert('hack')</script>). Muestra cómo la función htmlspecialchars() es la defensa crucial para evitar la ejecución del código al pintar el nombre.

    12. Validación de Contraseña con Longitud Mínima

    Crea un formulario de registro con un campo de contraseña. Valida que el campo no esté vacío y que su longitud sea de al menos 8 caracteres utilizando la función strlen(). Muestra errores específicos para cada condición fallida.

    13. Subida de Archivo: Validación de Tamaño y Tipo MIME

    Amplía el ejercicio 10. Antes de mover el fichero, valida que:

    1. El tamaño del fichero no exceda 1 MB (compara ['size']).
    2. El tipo MIME sea únicamente image/jpeg o image/png (compara ['type']).

    Si pasa la validación, muestra los metadatos. Si falla, detén el script con un mensaje de error.

    14. Acciones de Tabla Seguras (URL Encoding)

    Define un array de datos de productos. Genera una tabla donde la última columna sea un enlace "Ver Detalles". La URL de este enlace debe contener el nombre del producto, asegurándote de usar urlencode() al inyectar el nombre en el query string (?nombre=...).

    15. Creación de Clase SimpleValidator

    Crea una clase simple de validación (SimpleValidator) con los métodos __construct(), validate() y getErrors(). Implementa solo la regla required dentro del método validate() y haz que devuelva un array asociativo de errores.

    16. Validación de Datos con Regex

    Añade la regla zip_code a tu clase SimpleValidator. Implementa la lógica para usar preg_match() y verificar que un campo llamado codigo_postal contenga exactamente 5 dígitos numéricos.

    17. Integración del Flujo de Errores

    Crea un formulario de registro. Utiliza la clase SimpleValidator para validar los campos. Si la validación falla, imprime un único array de errores devuelto por el validador, mostrando las claves de los campos con problemas.

    18. Validación de Login con Lógica de Negocio

    En el ejemplo de Login (login.php), modifica el script para que, si el login es exitoso, utilice password_hash() y password_verify() para simular la comprobación de una contraseña encriptada (en lugar de comparar 1234 directamente).

    19. Implementación de Tokens CSRF Básico

    Investiga que es el CSRF ttoke y como implementarlo en php. Crea una función simple generateCsrfToken() que genere un token aleatorio y lo almacene en una variable. Modifica un formulario de contacto para incluir este token como campo oculto. El script de procesamiento debe verificar si el valor de $_POST['csrf_token'] existe y, aunque no lo compares con la sesión, valida que el token tenga una longitud mínima (por ejemplo, 64 caracteres) antes de procesar la solicitud.

    20. Subida de Fichero: Mover a Destino Seguro

    Completa el flujo de subida de ficheros:

    1. Valida tamaño, tipo MIME y que no haya error.
    2. Genera un nombre de fichero único y seguro utilizando uniqid() y basename().
    3. Utiliza la función move_uploaded_file() para mover el fichero de la ruta temporal (['tmp_name']) a una carpeta uploads/ con el nombre seguro. Muestra la ruta final al usuario.

    Ejercicios Prácticos: Cookies, Sesiones y Formularios

    Estos ejercicios combinan el manejo de la persistencia de datos (Cookies y Sesiones) con el flujo de trabajo de los formularios (POST/GET), incluyendo la simulación de login y el manejo de preferencias.

    1. Guardar Preferencia con Formulario y Cookie

    Crea un formulario con un select para elegir el color de fondo (blanco o negro). Al enviar el formulario (POST), el script debe guardar la selección en una cookie llamada tema_color con una duración de 24 horas.

    2. Lectura Condicional de Cookie

    En el mismo archivo del ejercicio 1, utiliza PHP embebido para leer la cookie tema_color. Si existe, aplica el color al <body> del HTML. Si la cookie no existe, usa un color por defecto (ej. blanco).

    3. Mensaje Único de Cookie

    Crea un formulario. Al enviarlo, establece una cookie de sesión (expiración a 0). En la siguiente recarga, lee la cookie y muestra un mensaje "Bienvenido de vuelta". Después de mostrar el mensaje, el script debe eliminar la cookie para que el mensaje solo se muestre una vez.

    4. Contador de Visitas con Sesión

    Crea una página. Utiliza session_start() al inicio. Comprueba si la variable $_SESSION['contador'] existe. Si no existe, inicialízala a 1. Si existe, increméntala. Muestra el número de veces que el usuario ha visitado la página.

    5. Formulario de Inicio de Sesión Simple con Sesión

    Modifica el ejemplo de Login de los apuntes. Si la validación es exitosa, en lugar de mostrar un mensaje de éxito, guarda el nombre de usuario en $_SESSION['user_name'] y redirige (header()) a una página de bienvenida (bienvenida.php).

    6. Página de Bienvenida y Redirección

    Crea la página bienvenida.php. Al inicio, comprueba si $_SESSION['user_name'] está establecida. Si lo está, muestra un saludo personalizado. Si no lo está, redirige al usuario de vuelta al formulario de login.

    7. Botón de Logout Básico

    Añade un enlace "Cerrar Sesión" en bienvenida.php que apunte a un script logout.php. Este script solo debe contener session_start() seguido de session_unset() y una redirección a la página de login.

    8. Carrito de Compra (Array de Sesión)

    Crea un formulario con un campo producto y un botón "Añadir al Carrito". Utiliza $_SESSION['carrito'] como un array para almacenar los productos. Si el formulario se envía, añade el producto al array. Muestra el contenido actual del carrito en una lista no ordenada (<ul>) usando foreach.

    9. Eliminación Selectiva del Carrito

    Añade a cada elemento de la lista del carrito (Ejercicio 8) un enlace "Eliminar" que pase el índice del array (?eliminar_indice=...) mediante GET. El script debe usar unset() en el índice correspondiente de $_SESSION['carrito'] para eliminar el ítem.

    10. Cookie de Última Visita

    Al cargar cualquier página, el script debe verificar si existe una cookie ultima_visita. Si existe, muestra: "Tu última visita fue el [Fecha/Hora]". Luego, actualiza la cookie con el timestamp actual para recordar la hora de esta visita.

    11. Login Seguro con Borrado Explícito de Contraseña

    Modifica el procesamiento del Login. Después de validar las credenciales, utiliza unset($_POST['password']) antes de realizar cualquier otra operación, demostrando la práctica de no mantener la contraseña en memoria más de lo necesario.

    12. Inyección de Atributo checked con Cookie

    Modifica el ejercicio 1 (Color de Fondo). El formulario debe tener dos radio buttons (<input type="radio">) para las opciones "Blanco" y "Negro". Utiliza PHP embebido y una expresión ternaria para inyectar el atributo checked en la opción que coincida con el valor de la cookie tema_color.

    13. Formulario con Múltiple Validación de Sesión

    Crea un formulario con dos campos. Utiliza tu clase SimpleValidator para validar ambos campos. Si la validación falla, guarda el array de errores ($validation_errors) y el array de datos de entrada ($data) en la sesión ($_SESSION). Después de la validación fallida, redirige al formulario (header()) y muestra los errores y los datos retenidos de la sesión.

    14. Bloqueo Condicional de Formulario

    Define una variable de sesión $_SESSION['compra_finalizada'] = true;. Crea un formulario de pedido. Utiliza PHP embebido y una expresión ternaria para inyectar el atributo disabled en el botón de envío si $_SESSION['compra_finalizada'] es verdadero.

    15. Cookie con Flag HttpOnly

    Modifica el script de creación de cookies (Ejercicio 1) para establecer la cookie preferencia_idioma con los flags Secure y HttpOnly en true (asumiendo que se ejecuta en un entorno HTTPS). ¿Por qué es importante HttpOnly?.

    16. Flujo de Login-Redirección-Acceso Condicional

    Crea un flujo de tres páginas: login.php, proceso_login.php y dashboard.php.

    1. proceso_login.php: Valida las credenciales. Si son correctas, inicia la sesión y guarda la ID. Redirige a dashboard.php.
    2. dashboard.php: Comprueba la sesión. Si no hay ID, redirige a login.php.

    17. Destrucción Segura de Sesión

    Crea un script logout.php que implemente el proceso de cierre de sesión completo y seguro:

    1. session_start(), session_unset(), session_destroy().
    2. Borrado explícito de la cookie de ID de sesión (PHPSESSID) con fecha pasada, utilizando session_get_cookie_params() y setcookie().

    18. Mensaje Flash de Sesión

    Implementa un sistema de mensajes flash: si un formulario se procesa con éxito, guarda un mensaje de confirmación ('msg' => 'Registro exitoso') en $_SESSION. En la página a la que rediriges, muestra el mensaje de la sesión, y luego elimina el mensaje de $_SESSION para que solo se muestre una vez.

    19. Clase SessionManager Encapsulada

    Crea una clase SessionManager con métodos estáticos como set(key, value), get(key), has(key) y flash(key, value). Asegúrate de que session_start() solo se llama una vez dentro del constructor o método de inicio de la clase, y utiliza esta clase para gestionar el carrito de compra (Ejercicio 8).

    20. Prevención de Secuestro de Sesión (Session Hijacking)

    Investiga la función session_regenerate_id(). Modifica el proceso_login.php (Ejercicio 16) para que, inmediatamente después de verificar que el login es exitoso, llame a esta función para generar una nueva ID de sesión antes de guardar los datos de usuario en $_SESSION. Explica en un comentario por qué esta es una buena práctica de seguridad.

    Ejercicios Prácticos: Autenticación, Autorización y Seguridad

    Estos ejercicios están diseñados para implementar los mecanismos de seguridad del lado del servidor, cubriendo el ciclo completo de login, logout, protección de páginas y control de acceso basado en roles.

    1. Flujo de Tres Páginas: Login y Redirección

    Crea las páginas login.php y privado.php. En login.php, crea un formulario POST simple. En privado.php, utiliza session_start() y una comprobación simple de isset($_SESSION['user_id']). Si la sesión NO existe, redirige inmediatamente a login.php.

    2. Cierre de Sesión Simple (logout.php)

    Crea el script logout.php. Este script debe contener session_start(), session_unset() y session_destroy(), seguido de una redirección a login.php.

    3. Mensaje de Error Único de Sesión

    Modifica el procesar_login.php del apunte. Si el login falla, guarda el mensaje "Credenciales inválidas" en $_SESSION['error_msg']. En login.php, muestra este mensaje usando código embebido y elimínalo inmediatamente con unset() después de mostrarlo.

    4. Hashing de Contraseña Único

    Crea un script simple. Define una contraseña simple (ej: 'clave123'). Utiliza password_hash() para generar el hash de esa contraseña y muéstralo en pantalla. Explica en un comentario por qué este hash cambia cada vez que se ejecuta el script.

    5. Verificación de Contraseña con password_verify

    Crea un script. Define una variable $hash_guardado con el hash del ejercicio 4. Define una variable $password_prueba con la contraseña original. Utiliza password_verify() y muestra "Contraseña OK" o "Contraseña Inválida".

    6. Uso de password_verify en el Procesador de Login

    Modifica el procesar_login.php para que la comprobación de contraseña se realice obligatoriamente con password_verify(), en lugar de una simple comparación de strings.

    7. Protección Básica contra XSS en Sesión

    Modifica el procesar_login.php. Cuando el usuario inicie sesión, no solo guardes la ID, sino también el nombre de usuario ($_POST['usuario']). Asegúrate de aplicar htmlspecialchars() al nombre de usuario antes de guardarlo en $_SESSION['user_name'].

    8. Protección CSRF en Formulario Simple

    Modifica el login.php. Añade una función generateCsrfToken() que genere un token único y lo almacene en $_SESSION['csrf_token']. Inyecta este token en el formulario como un campo oculto.

    9. Verificación CSRF en el Procesador

    Modifica procesar_login.php. Inmediatamente después de iniciar sesión, comprueba si $_POST['csrf_token'] es igual a $_SESSION['csrf_token']. Si no son iguales, detén el script con un die("Error CSRF").

    10. Guardar Rol en Sesión

    Modifica procesar_login.php. Si el login es exitoso, además de la ID, guarda el campo rol (ej: 'admin' o 'user') en $_SESSION['rol'].

    11. Autorización: Botón Condicional por Rol

    Modifica privado.php. Utiliza el rol guardado en la sesión. Muestra un botón "Panel de Control" únicamente si $_SESSION['rol'] es igual a 'admin'. Utiliza código embebido (if (...) { echo '...' }).

    12. Mensaje de Acceso Denegado (Redirección)

    Modifica privado.php. Si la comprobación de autenticación falla (!isset($_SESSION['usuario_id'])), antes de redirigir a login.php, guarda un mensaje en $_SESSION['error_denegado'] que diga: "Acceso denegado. Debe iniciar sesión."

    13. Borrado Explícito de Cookie de Sesión

    Modifica el script logout.php para implementar la destrucción completa de la sesión, incluyendo el borrado explícito de la cookie de ID de sesión (PHPSESSID) con session_get_cookie_params() y setcookie().

    14. Bloqueo de Página para Roles Específicos

    Crea una página reportes.php. En esta página, comprueba la sesión. Si el usuario existe pero su rol es 'lector', detén el script con un mensaje de error y un código de estado HTTP 403 (Forbidden) utilizando header('HTTP/1.0 403 Forbidden').

    15. Autenticación como Función Reutilizable

    Crea un fichero auth_helper.php con una función check_auth(). Esta función debe encapsular la lógica de privado.php (comprobar la sesión y redirigir si es necesario). Incluye este fichero al principio de privado.php y en cualquier otra página que deba ser protegida.

    16. Prevención de Secuestro de Sesión (Regeneración de ID)

    Modifica procesar_login.php. Inmediatamente después de verificar que la contraseña es correcta (y antes de guardar cualquier dato en $_SESSION), llama a la función session_regenerate_id(true). Explica en un comentario por qué esta es una defensa crítica.

    17. Clase Auth con Autenticación Encapsulada

    Crea una clase Auth con un método estático login($user, $pass). Este método debe encapsular la lógica de procesar_login.php (verificación de hash, guardado de sesión, session_regenerate_id).

    18. Clase Auth con Autorización Encapsulada

    Añade un método estático hasRole($rol_name) a la clase Auth (Ejercicio 17). Este método debe devolver true si $_SESSION['rol'] coincide con $rol_name. Utiliza este método en privado.php para controlar la visibilidad del botón de edición.

    19. Inyección Segura de Datos para Contraseña

    Investiga la función password_needs_rehash(). Modifica tu procesador de login para que, si el login es correcto y la contraseña almacenada requiere rehash (debido a un algoritmo más antiguo o a cambios de configuración), automáticamente calcule un nuevo hash y simule su actualización en la "base de datos" ($usuarios).

    20. Defensa Completa: CSRF + XSS + Login

    Combina los ejercicios de seguridad:

    1. Crea un formulario con Token CSRF y retención de datos fallidos.
    2. El procesar_login.php debe:
      • Verificar el Token CSRF.
      • Verificar la contraseña con password_verify().
      • Aplicar session_regenerate_id().
    3. Si falla la validación (CSRF o credenciales), redirige a login.php con un mensaje de error de sesión, asegurándote de que el mensaje de error también sea escapado con htmlspecialchars() antes de guardarse en $_SESSION.
