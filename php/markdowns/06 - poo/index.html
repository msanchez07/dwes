    Programación orientada a objetos

    La Programación Orientada a Objetos (POO) es un paradigma de programación que organiza el diseño de software alrededor de datos u objetos, en lugar de funciones y lógica. PHP es un lenguaje que soporta completamente la POO, permitiendo a los desarrolladores crear código más modular, reutilizable y fácil de mantener. La POO se basa en varios conceptos clave que, una vez comprendidos, transforman la forma en que se estructuran las aplicaciones.

    La POO se asienta sobre cuatro pilares principales:

    Clases

    Una clase es una plantilla o un "plano" para crear objetos. Define las propiedades (características o datos) y los métodos (comportamientos o funciones) que todos los objetos de ese tipo tendrán. Una clase en sí misma no almacena datos; es simplemente la definición de cómo serán los objetos.

    <?php
class Coche {
    // Propiedades (variables que describen el estado del coche)
    public $marca;
    public $modelo;
    public $color;

    // Métodos (funciones que describen el comportamiento del coche)
    public function arrancar() {
        return "El " . $this->marca . " " . $this->modelo . " está arrancando.";
    }

    public function frenar() {
        return "El coche está frenando.";
    }
}
?>

    Objetos

    Un objeto es una instancia de una clase. Cuando creas un objeto, estás creando una entidad real basada en el plano definido por la clase. Cada objeto tiene sus propios valores para las propiedades definidas por la clase.

    <?php
    // Crear (instanciar) un objeto de la clase Coche
    $miCoche = new Coche();

    // Asignar valores a las propiedades del objeto
    $miCoche->marca = "Toyota";
    $miCoche->modelo = "Corolla";
    $miCoche->color = "Rojo";

    // Llamar a los métodos del objeto
    echo $miCoche->arrancar(); // Salida: El Toyota Corolla está arrancando.
    echo "<br>";
    echo $miCoche->frenar();   // Salida: El coche está frenando.

    // Puedes crear múltiples objetos de la misma clase
    $otroCoche = new Coche();
    $otroCoche->marca = "Honda";
    $otroCoche->modelo = "Civic";
    $otroCoche->color = "Azul";

    echo "<br>";
    echo $otroCoche->arrancar(); // Salida: El Honda Civic está arrancando.
?>

    Dentro de los métodos de una clase, se utiliza la pseudo-variable $this para referirse al propio objeto actual, permitiendo acceder a sus propiedades y otros métodos.

    Propiedades y Métodos

    Las propiedades (atributos/variables de instancia) son las variables declaradas dentro de una clase que representan las características o el estado de un objeto.

    Por su parte, los métodos (funciones de instancia) son las funciones declaradas dentro de una clase que definen las acciones o comportamientos que un objeto puede realizar.

    Constructores (__construct())

    Un constructor es un método especial dentro de una clase que se ejecuta automáticamente cuando se crea una nueva instancia de esa clase (un nuevo objeto). Se utiliza comúnmente para inicializar las propiedades del objeto en el momento de su creación. En PHP, el método constructor se llama __construct().

    <?php
    class Persona {
        public $nombre;
        public $edad;

        // El constructor recibe parámetros para inicializar las propiedades
        public function __construct($nombre_inicial, $edad_inicial) {
            $this->nombre = $nombre_inicial;
            $this->edad = $edad_inicial;
        }

        public function obtenerInfo() {
            return $this->nombre . " tiene " . $this->edad . " años.";
        }
    }

    // Al crear el objeto, se pasan los argumentos al constructor
    $persona1 = new Persona("Luis", 30);
    $persona2 = new Persona("Marta", 25);

    echo $persona1->obtenerInfo(); // Salida: Luis tiene 30 años.
    echo "<br>";
    echo $persona2->obtenerInfo(); // Salida: Marta tiene 25 años.
?>

    Encapsulamiento

    El encapsulamiento es uno de los principios clave de la POO, que busca proteger los datos y ocultar los detalles internos de una clase, exponiendo solo lo necesario. Esto se logra mediante modificadores de acceso que controlan la visibilidad de las propiedades y métodos de una clase. PHP tiene tres modificadores de acceso:

    Public

    Las propiedades y métodos declarados como public son accesibles desde cualquier lugar: desde dentro de la propia clase, desde clases que la heredan y desde fuera de la clase (a través del objeto). Es el modificador por defecto si no se especifica ninguno.

    <?php
    class Producto {
        public $nombre;
        public function getNombre() {
            return $this->nombre;
        }
    }
    $p = new Producto();
    $p->nombre = "Laptop"; // Acceso público
    echo $p->getNombre();  // Acceso público al método
?>

    Protected

    Las propiedades y métodos protected son accesibles desde dentro de la propia clase y desde clases que la heredan (clases hijas). No son accesibles directamente desde fuera de la clase (a través del objeto).

    <?php
    class Animal {
        protected $nombre;

        public function __construct($n) {
            $this->nombre = $n;
        }

        protected function sonido() {
            return "hace un sonido...";
        }
    }

    class Perro extends Animal {
        public function ladrar() {
            return $this->nombre . " ladra: " . $this->sonido(); // Acceso a propiedad y método protected
        }
    }

    $miPerro = new Perro("Buddy");
    echo $miPerro->ladrar(); // Salida: Buddy ladra: hace un sonido...
    // echo $miPerro->nombre; // Error: No se puede acceder a una propiedad protected directamente
?>

    Private

    Las propiedades y métodos private son los más restrictivos. Solo pueden ser accedidos desde dentro de la propia clase donde fueron declarados. No son accesibles desde clases heredadas ni desde fuera de la clase. Se utilizan para ocultar la implementación interna.

    <?php
    class CuentaBancaria {
        private $saldo;

        public function __construct($saldoInicial) {
            $this->saldo = $saldoInicial;
        }

        public function depositar($monto) {
            if ($monto > 0) {
                $this->saldo += $monto;
            }
        }

        public function obtenerSaldo() {
            return $this->saldo; // Acceso privado permitido dentro de la clase
        }
    }

    $cuenta = new CuentaBancaria(100);
    $cuenta->depositar(50);
    echo "Saldo actual: " . $cuenta->obtenerSaldo(); // Salida: Saldo actual: 150
    // echo $cuenta->saldo; // Error: No se puede acceder a una propiedad private directamente
?>

    Herencia

    La herencia permite que una clase (la clase hija o subclase) herede propiedades y métodos de otra clase (la clase padre o superclase). Esto promueve la reutilización de código y establece una relación "es un tipo de" (por ejemplo, un Perro es un tipo de Animal). Se utiliza la palabra clave extends.

    <?php
    class Animal {
        public $especie;

        public function __construct($esp) {
            $this->especie = $esp;
        }

        public function comer() {
            return "El " . $this->especie . " está comiendo.";
        }
    }

    class Perro extends Animal { // Perro hereda de Animal
        public $raza;

        public function __construct($esp, $raz) {
            parent::__construct($esp); // Llama al constructor de la clase padre
            $this->raza = $raz;
        }

        public function ladrar() {
            return "El " . $this->raza . " " . $this->especie . " ladra.";
        }
    }

    $miPerro = new Perro("Canino", "Labrador");
    echo $miPerro->comer();   // Método heredado de Animal
    echo "<br>";
    echo $miPerro->ladrar(); // Método propio de Perro
    echo "<br>";
    echo "Es un " . $miPerro->especie . " de raza " . $miPerro->raza . ".";
?>

    Polimorfismo

    El polimorfismo es otro pilar fundamental de la Programación Orientada a Objetos que PHP soporta plenamente. La palabra "polimorfismo" significa "muchas formas", y en el contexto de la POO, se refiere a la capacidad de un objeto de tomar múltiples formas o, más precisamente, la capacidad de diferentes objetos de responder de manera diferente a un mismo mensaje (llamada de método). Esto se logra a menudo a través de la herencia de clases y la implementación de interfaces.

    El polimorfismo permite escribir código más genérico y flexible, ya que puedes interactuar con objetos de diferentes clases a través de una interfaz común o de una clase base.

    <?php
    // Clase Padre
    class Animal {
        public function hacerSonido() {
            return "El animal hace un sonido genérico.";
        }
    }

    // Clase Hija 1
    class Perro extends Animal {
        // Sobreescribe el método hacerSonido() de la clase padre
        public function hacerSonido() {
            return "El perro ladra: ¡Guau! ¡Guau!";
        }
    }

    // Clase Hija 2
    class Gato extends Animal {
        // Sobreescribe el método hacerSonido() de la clase padre
        public function hacerSonido() {
            return "El gato maúlla: ¡Miau! ¡Miau!";
        }
    }

    // Función que acepta cualquier objeto que sea un Animal (o un tipo de Animal)
    function comunicarSonido(Animal $animal) {
        echo $animal->hacerSonido() . "<br>";
    }

    // Creamos instancias de las clases
    $animalGenerico = new Animal();
    $miPerro = new Perro();
    $miGato = new Gato();

    // Llamamos a la función genérica con diferentes tipos de objetos
    comunicarSonido($animalGenerico); // Salida: El animal hace un sonido genérico.
    comunicarSonido($miPerro);       // Salida: El perro ladra: ¡Guau! ¡Guau!
    comunicarSonido($miGato);        // Salida: El gato maúlla: ¡Miau! ¡Miau!

    // También puedes llamar al método directamente en el objeto
    echo $miPerro->hacerSonido() . "<br>";
    echo $miGato->hacerSonido() . "<br>";
?>

    En este ejemplo, la función comunicarSonido() no necesita saber si está tratando con un Perro o un Gato; solo sabe que es un Animal y que todos los Animales tienen un método hacerSonido(). El polimorfismo garantiza que el método hacerSonido() ejecutado sea el correcto para el tipo de objeto específico.

    Interfaces

    Las interfaces son otro mecanismo poderoso para implementar polimorfismo en PHP. Una interfaz define un conjunto de métodos que una clase debe implementar. Es como un "contrato": cualquier clase que "implemente" una interfaz se compromete a proporcionar una implementación para todos los métodos definidos en esa interfaz. Las interfaces no contienen implementaciones de métodos, solo sus firmas (nombre, parámetros).

    <?php
    // Definición de una interfaz
    interface Volador {
        public function volar();
        public function aterrizar();
    }

    // Clase que implementa la interfaz Volador
    class Avion implements Volador {
        public function volar() {
            return "El avión está despegando y volando alto.";
        }

        public function aterrizar() {
            return "El avión está aterrizando en la pista.";
        }
    }

    // Otra clase que implementa la misma interfaz
    class Pajaro implements Volador {
        public function volar() {
            return "El pájaro bate sus alas y se eleva.";
        }

        public function aterrizar() {
            return "El pájaro se posa suavemente en la rama.";
        }
    }

    // Una función que espera cualquier objeto que implemente la interfaz Volador
    function hacerVolar(Volador $objetoVolador) {
        echo $objetoVolador->volar() . "<br>";
        echo $objetoVolador->aterrizar() . "<br>";
    }

    // Creamos instancias
    $miAvion = new Avion();
    $miPajaro = new Pajaro();

    // Llamamos a la función polimórfica
    hacerVolar($miAvion);
    echo "---<br>";
    hacerVolar($miPajaro);
?>

    En este ejemplo, hacerVolar() puede operar con Avion o Pajaro porque ambos garantizan que tienen los métodos volar() y aterrizar() gracias a la interfaz Volador. El comportamiento exacto de volar() o aterrizar() es específico de cada clase, lo que demuestra el polimorfismo.

    Clases abstractas

    Además de las interfaces, PHP ofrece las clases abstractas como otra herramienta poderosa para definir contratos y estructuras jerárquicas en la POO. Una clase abstracta es una clase que no puede ser instanciada directamente (no puedes crear objetos de ella), pero puede ser heredada por otras clases. Su propósito principal es servir como una base para otras clases, definiendo métodos que las clases hijas deben implementar.

    Las clases abstractas pueden contener:

    • Propiedades y métodos concretos: Métodos con una implementación completa, como los de una clase normal.
    • Métodos abstractos: Métodos declarados sin implementación (sin cuerpo {}). Cualquier clase hija que herede de una clase abstracta debe proporcionar una implementación para todos los métodos abstractos de la clase padre.

    Para declarar una clase o un método como abstracto, se utiliza la palabra clave abstract.

    <?php
    // Clase abstracta Publicacion
    abstract class Publicacion {
        public $titulo;
        public $autor;
        public $fecha;

        public function __construct($titulo, $autor, $fecha) {
            $this->titulo = $titulo;
            $this->autor = $autor;
            $this->fecha = $fecha;
        }

        // Método concreto para obtener información básica, común a todas las publicaciones
        public function getInfoBasica() {
            return "Título: " . $this->titulo . " | Autor: " . $this->autor . " | Fecha: " . $this->fecha;
        }

        // Método abstracto que las clases hijas DEBEN implementar
        abstract public function mostrarContenido();
    }

    // Clase Hija Articulo, que hereda de Publicacion
    class Articulo extends Publicacion {
        public $contenido;

        public function __construct($titulo, $autor, $fecha, $contenido) {
            parent::__construct($titulo, $autor, $fecha);
            $this->contenido = $contenido;
        }

        // Implementación del método abstracto mostrarContenido()
        public function mostrarContenido() {
            return "<h3>" . $this->titulo . "</h3>" .
                "<p><em>Por " . $this->autor . " el " . $this->fecha . "</em></p>" .
                "<p>" . $this->contenido . "</p>";
        }
    }

    // Clase Hija Noticia, que también hereda de Publicacion
    class Noticia extends Publicacion {
        public $resumen;

        public function __construct($titulo, $autor, $fecha, $resumen) {
            parent::__construct($titulo, $autor, $fecha);
            $this->resumen = $resumen;
        }

        // Implementación del método abstracto mostrarContenido()
        public function mostrarContenido() {
            return "<h4>NOTICIA: " . $this->titulo . "</h4>" .
                "<p>Resumen: " . $this->resumen . "</p>" .
                "<p><em>Fuente: " . $this->autor . ", " . $this->fecha . "</em></p>";
        }
    }

    // Intentar instanciar una clase abstracta directamente resultaría en un error:
    // $publicacionBase = new Publicacion("Titulo Base", "Autor Base", "2025-07-30"); // Fatal error

    $miArticulo = new Articulo(
        "La Importancia del PHP Moderno",
        "Desarrollador Experto",
        "2025-07-29",
        "PHP ha evolucionado significativamente, ofreciendo..."
    );

    $miNoticia = new Noticia(
        "Nuevo Lanzamiento de PHP 9.0",
        "Agencia de Noticias Tech",
        "2025-07-30",
        "La próxima versión de PHP promete mejoras drásticas en rendimiento y sintaxis..."
    );

    echo $miArticulo->getInfoBasica() . "<br>";
    echo $miArticulo->mostrarContenido() . "<br><br>";

    echo $miNoticia->getInfoBasica() . "<br>";
    echo $miNoticia->mostrarContenido() . "<br>";
?>

    En este ejemplo, Publicacion es abstracta porque no tiene sentido crear una "publicación" genérica; siempre será un tipo específico de publicación (Artículo, Noticia, etc.). Sin embargo, todos los tipos de publicación tienen un título, autor, fecha, y la necesidad de mostrarContenido(), aunque la forma en que lo muestran varía.
