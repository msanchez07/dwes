    Funciones

    Las funciones son bloques de código autocontenidos y reutilizables que realizan una tarea específica. Su propósito principal es organizar el código, evitar la repetición y hacer los programas más modulares, legibles y fáciles de mantener. En PHP, puedes utilizar funciones predefinidas del lenguaje o crear tus propias funciones personalizadas.

    Declaración y Llamada de Funciones Personalizadas

    Para crear una función en PHP, se utiliza la palabra clave function, seguida del nombre de la función, un par de paréntesis (que pueden contener parámetros) y un bloque de código entre llaves {}.

    <?php
    function nombreDeLaFuncion() {
        // Código a ejecutar cuando se llama a la función
    }
?>

    Para ejecutar el código dentro de una función, simplemente debes "llamarla" por su nombre, seguido de paréntesis.

    <?php
    function saludar() {
        echo "¡Hola desde mi primera función!";
    }

    // Llamar a la función
    saludar(); // Salida: ¡Hola desde mi primera función!
?>

    Las funciones pueden aceptar parámetros, que son valores de entrada que la función necesita para realizar su tarea. Cuando llamas a la función, los valores que le pasas se llaman argumentos.

    <?php
    function saludarPersonalizado($nombre) {
        echo "¡Hola, " . $nombre . "!";
    }

    // Llamar a la función con un argumento
    saludarPersonalizado("Ana"); // Salida: ¡Hola, Ana!
    echo "<br>";
    saludarPersonalizado("Pedro"); // Salida: ¡Hola, Pedro!
?>

    Puedes definir valores por defecto para los parámetros. Si no se proporciona un argumento al llamar a la función, se utilizará el valor por defecto.

    <?php
    function saludarConPorDefecto($nombre = "Invitado") {
        echo "¡Bienvenido, " . $nombre . "!";
    }

    saludarConPorDefecto("María"); // Salida: ¡Bienvenido, María!
    echo "<br>";
    saludarConPorDefecto(); // Salida: ¡Bienvenido, Invitado!
?>

    Valores de retorno

    Las funciones no solo pueden realizar una acción (como imprimir algo), sino que también pueden devolver un valor al punto desde donde fueron llamadas. Esto se hace con la palabra clave return. Cuando PHP encuentra una sentencia return, la función termina inmediatamente y el valor especificado es devuelto.

    <?php
    function sumar($num1, $num2) {
        $resultado = $num1 + $num2;
        return $resultado; // Devuelve el resultado de la suma
    }

    $total = sumar(5, 3); // La función devuelve 8, que se almacena en $total
    echo "La suma es: " . $total; // Salida: La suma es: 8

    echo "<br>";
    echo "Otra suma: " . sumar(10, 20); // Salida: Otra suma: 30
?>

    Una función puede devolver cualquier tipo de dato: números, cadenas, booleanos, arrays, objetos o incluso NULL.

    Ámbito (Scope) de las Variables

    El ámbito de una variable se refiere a la parte del script donde esa variable puede ser accedida o utilizada. En PHP, las variables declaradas dentro de una función tienen un ámbito local; esto significa que solo pueden ser accedidas desde dentro de esa función. Las variables declaradas fuera de cualquier función tienen un ámbito global y no son automáticamente accesibles dentro de las funciones.

    <?php
    $mensaje_global = "Soy una variable global."; // Ámbito global

    function mostrarMensaje() {
        $mensaje_local = "Soy una variable local."; // Ámbito local
        echo $mensaje_local; // Esto funciona
        // echo $mensaje_global; // Esto NO funciona directamente (generaría un error si no se usa 'global')
    }

    mostrarMensaje(); // Salida: Soy una variable local.
    echo "<br>";
    echo $mensaje_global; // Salida: Soy una variable global.
    // echo $mensaje_local; // Esto NO funciona (fuera de su ámbito)
?>

    Para acceder a una variable global desde dentro de una función, puedes usar la palabra clave global o la superglobal $_GLOBAL[] (un array asociativo que contiene todas las variables globales).

    <?php
    $contador = 0; // Variable global

    function incrementarContador() {
        global $contador; // Declara que $contador se refiere a la variable global
        $contador++;
    }

    incrementarContador();
    incrementarContador();
    echo "El contador global es: " . $contador; // Salida: El contador global es: 2
?>

    <?php
    $base = 10;

    function duplicarBase() {
        $GLOBALS['base'] = $GLOBALS['base'] * 2;
    }

    duplicarBase();
    echo "La base duplicada es: " . $base; // Salida: La base duplicada es: 20
?>

    Paso de Funciones como Argumento: Callbacks y Closures

    En PHP, las funciones son consideradas "ciudadanos de primera clase", lo que significa que pueden ser tratadas como cualquier otro valor: se pueden asignar a variables, devolver desde otras funciones y, lo que es más importante para esta sección, se pueden pasar como argumento a otras funciones.

    Una función que acepta otra función como argumento se conoce como una función de orden superior (higher-order function). La función que se pasa como argumento se denomina comúnmente "callback". Esta capacidad permite crear código extremadamente flexible y reutilizable, ya que podemos definir un comportamiento general en una función y pasarle la acción específica que debe realizar como un parámetro.

    Para indicar que un argumento debe ser una función, utilizamos el tipo de dato callable.

    El Concepto en la Práctica

    Imaginemos que queremos crear una función que procese cada elemento de un array. En lugar de crear una función para duplicar los números, otra para convertirlos en negativos, etc., podemos crear una única función genérica y pasarle la operación a realizar.

    <?php
// Nuestra función de orden superior. Acepta un array y una función (callable).
function procesar_array(array $numeros, callable $callback) {
    $resultado = [];
    foreach ($numeros as $numero) {
        // Llama a la función callback con cada elemento y guarda el resultado.
        $resultado[] = $callback($numero);
    }
    return $resultado;
}

// Definimos una función que será nuestro callback.
function duplicar($n) {
    return $n * 2;
}

// Usamos nuestra función de orden superior, pasándole 'duplicar' como argumento.
$lista_numeros = [1, 2, 3, 4];
$numeros_duplicados = procesar_array($lista_numeros, 'duplicar');

print_r($numeros_duplicados); // Salida: Array ( [0] => 2 [1] => 4 [2] => 6 [3] => 8 )

    Funciones Anónimas (Closures)

    Crear una función con nombre solo para usarla una vez como callback puede ser un poco engorroso. La forma más moderna y común de hacer esto es utilizando funciones anónimas, también conocidas como closures. Son funciones sin nombre que se definen directamente en el lugar donde se necesitan.

    <?php
// Reutilizamos nuestra función procesar_array.
$lista_numeros = [1, 2, 3, 4];

// En lugar de pasar el nombre de una función, la definimos directamente aquí.
$numeros_triplicados = procesar_array($lista_numeros, function($n) {
    return $n * 3;
});

print_r($numeros_triplicados); // Salida: Array ( [0] => 3 [1] => 6 [2] => 9 [3] => 12 )

    Funciones Predefinidas

    Una de las mayores fortalezas de PHP es su extensa librería estándar, un enorme conjunto de funciones predefinidas que vienen integradas en el lenguaje y están listas para ser utilizadas sin necesidad de instalar nada adicional. Podemos pensar en ellas como una caja de herramientas gigante que nos proporciona soluciones para miles de problemas comunes.

    Saber utilizar estas funciones es fundamental para ser un programador de PHP eficiente. En lugar de tener que "reinventar la rueda" y escribir código para tareas comunes como contar los caracteres de un texto, ordenar una lista de números o formatear una fecha, podemos simplemente llamar a una función que ya ha sido creada, probada y optimizada por los desarrolladores del lenguaje.

    Existen literalmente miles de funciones predefinidas, y es imposible memorizarlas todas. La habilidad clave no es saberlas de memoria, sino saber que existen, entender en qué categorías se agrupan y ser capaz de consultar rápidamente la documentación oficial de PHP (php.net) para entender cómo se usan.
