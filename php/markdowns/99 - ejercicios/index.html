    Ejercicios

    Ejercicios de Programación Estructurada

    1. Suma de dos números

    Escribe un programa que solicite al usuario ingresar dos números y muestre la suma de ambos.

    2. Par o impar

    Crea un programa que pida un número al usuario y determine si es par o impar.

    3. Tabla de multiplicar

    Solicita un número al usuario y muestra su tabla de multiplicar del 1 al 10.

    4. Número mayor

    Escribe un programa que reciba dos números y muestre cuál de ellos es mayor. Si son iguales, indicarlo.

    5. Conteo de vocales

    Pide al usuario una palabra y cuenta cuántas vocales tiene.

    6. Conversor de temperatura

    Crea un programa que convierta una temperatura dada en grados Celsius a Fahrenheit. La fórmula es: F = C * 9/5 + 32.

    7. Calculadora básica

    Implementa una calculadora que realice operaciones de suma, resta, multiplicación y división según la opción que elija el usuario.

    8. Factorial de un número

    Escribe un programa que calcule el factorial de un número ingresado por el usuario.

    9. Número primo

    Crea un programa que determine si un número ingresado es primo o no.

    10. Promedio de calificaciones

    Solicita al usuario que ingrese tres calificaciones y calcula el promedio. Indica si el promedio es aprobado (mayor o igual a 6) o reprobado.

    11. Serie de Fibonacci

    Escribe un programa que genere los primeros n números de la serie de Fibonacci. El usuario debe ingresar el valor de n.

    12. Invertir cadena

    Crea un programa que invierta una cadena ingresada por el usuario sin utilizar funciones integradas como reverse() o slicing.

    13. Segundo número más grande

    Escribe un programa que encuentre el segundo número más grande en una lista de números ingresada por el usuario.

    14. Palíndromo

    Crea un programa que determine si una palabra ingresada por el usuario es un palíndromo.

    15. Fusión de diccionarios

    Escribe un programa que fusione dos diccionarios proporcionados por el usuario en uno solo. Si hay claves duplicadas, los valores del segundo diccionario deben sobrescribir los del primero.

    16. Frecuencia de caracteres

    Crea un programa que cuente la frecuencia de cada carácter en una cadena ingresada por el usuario y muestre los resultados en un diccionario.

    17. Agenda de contactos

    Implementa un programa que permita al usuario agregar, buscar y eliminar contactos en un libro de contactos utilizando diccionarios.

    18. Conteo de palabras en archivo

    Escribe un programa que lea un archivo de texto y cuente el número total de palabras que contiene.

    19. Ordenar tuplas

    Crea un programa que ordene una lista de tuplas basándose en el segundo elemento de cada tupla.

    20. Generador de números primos

    Escribe un programa que genere todos los números primos hasta un número n ingresado por el usuario.

    21. Calculadora científica

    Implementa una calculadora científica que soporte operaciones básicas y avanzadas como potencias, raíces cuadradas, logaritmos y funciones trigonométricas.

    22. Gestión de inventario

    Crea un programa para gestionar el inventario de una tienda, permitiendo agregar, eliminar, actualizar y listar productos, con persistencia en archivos.

    23. Análisis de ventas desde CSV

    Desarrolla un programa que lea un archivo CSV con datos de ventas y calcule estadísticas como total de ventas, producto más vendido, etc.

    24. Gestión de estudiantes

    Implementa un sistema para gestionar información de estudiantes (ID, nombre, edad, calificaciones), permitiendo agregar, eliminar, actualizar y buscar.

    25. Juego de adivinanza

    Crea un juego de adivinanza con niveles de dificultad, donde el usuario debe adivinar un número generado aleatoriamente.

    26. Simulación de sistema bancario

    Desarrolla una simulación de un sistema bancario que permita crear cuentas, depositar, retirar y consultar saldo.

    27. Estadísticas de archivo de texto

    Crea un programa que lea un archivo de texto y calcule estadísticas como número de palabras, caracteres y frecuencia de palabras.

    28. Conversor de unidades

    Desarrolla un conversor de unidades para longitud, peso y temperatura.

    29. Gestión de reservas de biblioteca

    Implementa un sistema para gestionar reservas de libros en una biblioteca.

    Ejercicios de Programación Orientada a Objetos

    1. Clase Persona

    Crea una clase Persona con atributos como nombre, edad y correo. Implementa un método que muestre la información de la persona.

    2. Herencia con Coches

    Crea una clase Coche con atributos como marca, modelo y año. Luego, crea una clase Electrico que herede de Coche y añada el atributo autonomia.

    3. Contactos en archivo

    Crea un programa que permita agregar contactos (nombre y teléfono) a un archivo de texto y luego listar todos los contactos almacenados.

    4. Clase Libro

    Crea una clase Libro con atributos como titulo, autor y precio. Implementa un método que aplique un descuento al precio del libro.

    5. Cuenta Bancaria

    Crea una clase CuentaBancaria con atributos como titular y saldo. Implementa métodos para depositar, retirar y mostrar el saldo actual.

    6. Promedio

    Crea un programa que calcule el promedio de calificaciones de un estudiante con una clase Estudiante (nombre, edad, nota).

    7. Método __toString() para Empleado

    Crea una clase Empleado con atributos nombre, puesto y salario. Implementa el método especial __toString() para representar al empleado como una cadena de texto.

    8. Manejo de excepciones

    Crea un programa que lance una excepción y maneje esta excepción, mostrando un mensaje de error.

    9. Herencia con Animales

    Crea una clase base Animal con atributos nombre y edad. Luego, crea clases derivadas como Perro y Gato que hereden de Animal y añadan métodos específicos.

    10. Guardar y leer JSON

    Crea una clase Producto con atributos id, nombre y precio. Implementa métodos para guardar una lista de productos en un archivo JSON y para leerlos desde el archivo.

    11. Sistema de Reservas de Vuelos

    Crea una jerarquía de clases para gestionar reservas de vuelos (Vuelo, Reserva, ReservaPremium) con métodos para reservar, cancelar y mostrar detalles.

    12. Gestión de Biblioteca

    Implementa un sistema para gestionar libros en una biblioteca usando clases Libro y Biblioteca, con persistencia en JSON.

    13. Análisis de Ventas desde Excel

    Crea un programa que lea un archivo Excel con datos de ventas y calcule el total de ventas por producto, utilizando la librería openpyxl.

    14. Encapsulación con Getters y Setters

    Crea una clase Persona que tenga atributos privados para nombre y edad. Implementa métodos getters y setters para acceder y modificar estos atributos.

    15. Historial de Transacciones

    Crea una clase CuentaCorriente que permita realizar depósitos y retiros, y mantenga un historial de transacciones.

    16. Serialización con Pickle

    Crea un programa que guarde una lista de objetos en un archivo binario utilizando la librería pickle y luego los recupere.

    17. Atributos de Clase

    Crea una clase Vehiculo con un atributo de clase total_vehiculos que se incremente con cada nueva instancia.

    18. Análisis de Archivo de Log

    Desarrolla un programa que analice un archivo de registro (log) y cuente la cantidad de veces que aparece cada tipo de error.

    19. Polimorfismo con Estudiantes

    Crea una clase base Estudiante con un método calcular_promedio. Luego, crea clases derivadas (EstudiantePregrado, EstudiantePosgrado) que implementen el método de manera diferente.

    20. Serialización de Usuarios a JSON

    Crea una clase Usuario con atributos usuario y contraseña. Implementa métodos para serializar y deserializar objetos de esta clase a y desde un archivo JSON.

    21. Gestión de Inventario con SQLite

    Implementa un sistema completo de gestión de inventario utilizando POO, con la información de los productos almacenada en una base de datos SQLite.

    22. Parser de XML

    Desarrolla una clase ParserXML que lea un archivo XML y convierta su contenido en objetos de PHP.

    23. Sistema de Facturación

    Crea un sistema de facturación que permita generar facturas, guardarlas en archivos de texto y leerlas, utilizando clases como Factura y Cliente.

    24. Clases Abstractas

    Crea una clase abstracta Empleado con un método abstracto calcular_salario e impleméntalo en clases derivadas.

    25. Herencia Múltiple

    Crea clases que representen dispositivos electrónicos utilizando herencia múltiple (ej. Smartphone hereda de Telefono y Computadora).

    26. Gestión de Proyectos y Tareas

    Crea una clase Proyecto que gestione tareas (agregar, eliminar, listar) y guarde la información en un archivo CSV.

    27. Ampliación de Sistema de Biblioteca

    Amplía el sistema de biblioteca para incluir préstamos y devoluciones, manteniendo un registro en archivos JSON.

    Ejercicios de Código Embebido

    1. Información del sistema

    Muestra en una página HTML los siguientes datos generados por PHP:

    - Versión de PHP instalada
- Fecha y hora actual
- Nombre del archivo actual (__FILE__)

    2. Variables en HTML

    Declara variables $nombre, $curso, $anio y píntalas en una estructura HTML que las muestre como una ficha de estudiante. Se valorará la parte visual.

    3. Números del 1 al 10 en lista

    Utiliza un bucle for en PHP para generar dinámicamente una lista ul con los números del 1 al 10.

    4. Tabla de multiplicar (embebida)

    Genera con PHP una tabla HTML de multiplicar del 1 al 10. Cada fila debe representar un número base y sus productos.

    5. Colores alternos en tabla

    Crea una tabla de 10 filas y 3 columnas. Usa PHP para alternar el color de fondo de las filas (por ejemplo, gris y blanco).

    6. Array de alumnos

    Define un array de nombres y muestra cada uno dentro de una lista ordenada ol.

    7. Tabla de productos

    Crea un array asociativo con productos (nombre, precio, stock) y genera una tabla HTML que los muestre.

    8. Destacar el producto más caro

    A partir del array anterior, aplica un estilo CSS (por ejemplo, color de fondo) al producto con el precio más alto.

    9. Lista de meses

    Genera una lista HTML con los 12 meses del año. El mes actual debe mostrarse destacado (negrita o color distinto).

    10. Botones generados por PHP

    Crea un array con etiquetas como “Inicio”, “Productos”, “Contacto” y genera dinámicamente botones

    11. Mini calendario de una semana

    Muestra en una tabla HTML los días de una semana (lunes a domingo), usando PHP para generarlos dinámicamente.

    12. Tabla de empleados con formato

    Usa un array multidimensional con empleados (nombre, puesto, salario) y genera una tabla con cabecera. Si el salario supera cierta cantidad, resáltalo en verde.

    13. Lista numerada con estilo

    Genera con un bucle for una lista ordenada de los números pares del 2 al 20. Aplica un color de texto distinto para los múltiplos de 4.

    14. Generación de etiquetas HTML desde PHP

    Usa un array de nombres de etiquetas (h1, p, div, span) y genera ejemplos de cada una con contenido dentro, usando PHP para imprimirlas.

    15. Rejilla de imágenes

    Crea un array con rutas de imágenes (pueden ser URLs o ficheros locales). Muestra las imágenes en una cuadrícula 3x3 generada con un bucle foreach.

    16. Ficha de usuario con datos simulados

    Define variables $nombre, $edad, $correo, $foto y genera una ficha HTML de presentación (similar a un perfil de usuario).

    17. Tarjetas de productos

    Crea un array con 5 productos y muéstralos en “tarjetas” (divs) que contengan nombre, descripción y precio. Usa PHP para generar las tarjetas dentro de un contenedor section.

    18. Menú de navegación dinámico

    Define un array con los nombres de secciones (Inicio, Servicios, Portfolio, Contacto) y genera una barra de navegación con enlaces a.

    19. Tabla de notas con promedio

    Crea un array asociativo donde cada alumno tiene un nombre y tres notas y múestralo en una tabla. Calcula y muestra el promedio en una columna adicional.

    20. Lista de tareas completadas

    Crea un array con tareas, donde cada elemento tiene texto y completada (true/false). Muestra una lista con un ✔️ o ❌ según su estado.

    21. Cita aleatoria del día

    Define un array con frases o citas motivacionales. Muestra una aleatoria cada vez que se recargue la página.

    22. Tablero de ajedrez

    Usa PHP para generar una tabla 8x8 que simule un tablero de ajedrez alternando los colores de las celdas.

    23. Mapa de enlaces

    Crea un array con nombres y URLs. Muestra los enlaces en una tabla con dos columnas: nombre y dirección.

    24. Generador de botones de redes sociales

    Crea un array con nombres de redes (Facebook, Twitter, Instagram) y genera botones con sus iconos e hipervínculos.

    25. Página resumen de empresa

    Combina todo: crea arrays para empleados, productos y contactos, y genera una página HTML que muestre:

    - Tabla de empleados
- Lista de productos destacados
- Pie con información de contacto

    Todo generado dinámicamente con PHP embebido.

    26. Página resumen de empresa

    Combina todo: crea arrays para empleados, productos y contactos, y genera una página HTML que muestre:

    - Tabla de empleados
- Lista de productos destacados
- Pie con información de contacto

    Todo generado dinámicamente con PHP embebido.

    27. Calendario

    Crea una funcionalidad que muestre un calendario para un mes y un año. El més y el año se pueden indicar en variables. En caso de que se cambie el mes o el año, el calendario debe cambiar. Se deben marcar los días festivos en rojo.

    28. Menú reutilizable

    Crea un archivo menu.php que contenga una lista de navegación con enlaces (Inicio, Productos, Contacto). Inclúyelo con require en tres páginas distintas (index.php, productos.php, contacto.php) para simular un sitio con estructura común.

    28. Reutilización de funciones

    Crea un archivo funciones.php con dos funciones:

    - saludar($nombre) → muestra un saludo personalizado
- mostrarFecha() → imprime la fecha actual

    Luego crea una página index.php que requiera ese archivo y utilice ambas funciones para mostrar contenido.

    29. Plantilla de contenido

    Crea una estructura de plantilla con:

    - header.php (cabecera)
- sidebar.php (barra lateral con secciones)
- content.php (contenido principal generado por PHP)
- footer.php (pie)

    El archivo principal index.php debe usar require_once o include_once para montar toda la página completa.

    30. Inclusión condicional

    Crea un archivo config.php con una variable $modo = "produccion" o "desarrollo". En index.php, usa una sentencia condicional para incluir diferentes archivos de configuración según el modo activo. Por ejemplo:

    - Si $modo = "desarrollo" → incluir config_dev.php
- Si $modo = "produccion" → incluir config_prod.php

    Muestra un mensaje en pantalla indicando qué archivo fue cargado.

    31. Página modular con componentes dinámicos

    Crea una pequeña página web que utilice varios archivos PHP incluidos para simular una estructura de sitio real:

    - `index.php`: archivo principal que monta toda la página.  
- `includes/header.php`: contiene el título del sitio y un subtítulo generado con una variable PHP (`$subtitulo = "Aprendiendo PHP embebido"`).  
- `includes/banner.php`: muestra una frase motivacional o un mensaje aleatorio (elige entre 3 frases almacenadas en un array).  
- `includes/footer.php`: muestra el año actual y el nombre del autor, usando `require_once`.

    En index.php, utiliza include para la cabecera y el banner, y require para el pie de página.
    El resultado debe mostrar una página completa ensamblada con partes reutilizables y datos dinámicos.
