    Arrays

    Un array es una de las estructuras de datos más fundamentales y potentes de PHP. En esencia, es una variable especial que permite almacenar múltiples valores en un único lugar. Técnicamente, un array en PHP es un "mapa ordenado", es decir, una colección de pares clave => valor, donde cada valor está asociado a una clave única.

    La gran versatilidad de los arrays en PHP reside en que pueden ser utilizados de varias maneras:

    • Como un array indexado, que funciona como una lista simple donde cada valor tiene un índice numérico (0, 1, 2...).
    • Como un array asociativo, que funciona como un diccionario donde cada valor está asociado a una clave con nombre (p. ej., 'nombre' => 'Ana').
    • Como un array multidimensional, que es un array que contiene otros arrays, permitiendo crear estructuras complejas como tablas o matrices.

    Los arrays son la herramienta principal para trabajar con conjuntos de datos, ya sea una lista de usuarios extraída de una base de datos, los productos en un carrito de la compra o las opciones de un menú. En las siguientes secciones, exploraremos cómo crear, acceder y manipular los datos contenidos en ellos.

    Arrays indexados

    Un array indexado es la forma más fundamental de un array en PHP. Podemos imaginarlo como una lista simple y ordenada de valores, donde cada elemento ocupa una posición específica. Esta posición se identifica mediante un índice numérico, que por defecto comienza en cero para el primer elemento, uno para el segundo, y así sucesivamente. Son la estructura ideal cuando el orden de los elementos es importante y no necesitamos asignarles un nombre descriptivo, como en una lista de tareas pendientes o los resultados de una encuesta.

    Para acceder a un elemento concreto dentro de un array indexado, se utiliza su índice numérico. De la misma manera, podemos modificar un valor existente o añadir uno nuevo al final de la lista. La función count() es una herramienta esencial al trabajar con ellos, ya que nos permite saber cuántos elementos contiene el array en un momento dado, lo cual es crucial para poder recorrer la colección completa mediante bucles.

    <?php

// ----------------------------------------------------
// 1. CREACIÓN DE UN ARRAY INDEXADO
// ----------------------------------------------------
// Un array indexado es una lista simple y ordenada.
// PHP asigna los índices numéricos automáticamente (0, 1, 2...).
$tareas = ["Comprar leche", "Hacer ejercicio", "Estudiar PHP"];

// Mostramos el contenido del array para ver su estructura
echo "<strong>Array inicial:</strong><br>";
print_r($tareas);
echo "<hr>";


// ----------------------------------------------------
// 2. ACCESO A UN ELEMENTO CONCRETO
// ----------------------------------------------------
// Se accede a los elementos usando su índice numérico entre corchetes [].
echo "<strong>Accediendo a elementos:</strong><br>";
echo "La primera tarea (índice 0) es: " . $tareas[0] . "<br>"; // Salida: Comprar leche
echo "La tercera tarea (índice 2) es: " . $tareas[2] . "<br>"; // Salida: Estudiar PHP
echo "<hr>";


// ----------------------------------------------------
// 3. MODIFICAR UN ELEMENTO
// ----------------------------------------------------
// Se modifica un valor simplemente asignando uno nuevo a un índice existente.
$tareas[1] = "Pasear al perro"; // Cambiamos "Hacer ejercicio" por "Pasear al perro"

echo "<strong>Array con el segundo elemento modificado:</strong><br>";
print_r($tareas);
echo "<hr>";


// ----------------------------------------------------
// 4. AÑADIR UN ELEMENTO AL FINAL
// ----------------------------------------------------
// Usando corchetes vacíos [] se añade un elemento al final del array.
$tareas[] = "Llamar a Ana";

echo "<strong>Array con un nuevo elemento añadido al final:</strong><br>";
print_r($tareas);
echo "<hr>";


// ----------------------------------------------------
// 5. USAR LA FUNCIÓN count()
// ----------------------------------------------------
// count() nos dice cuántos elementos hay en el array.
$numero_de_tareas = count($tareas);
echo "<strong>Uso de count():</strong><br>";
echo "Ahora tienes un total de " . $numero_de_tareas . " tareas pendientes."; // Salida: 4
echo "<hr>";


// ----------------------------------------------------
// 6. RECORRER LA COLECCIÓN COMPLETA (BUCLE)
// ----------------------------------------------------
// Un bucle 'for' es ideal para recorrer un array indexado.
echo "<strong>Recorriendo el array con un bucle for:</strong><br>";
for ($i = 0; $i < $numero_de_tareas; $i++) {
    // Usamos la variable $i para acceder a cada índice dinámicamente
    echo "Tarea " . ($i + 1) . ": " . $tareas[$i] . "<br>";
}

?>

    Arrays Asociativos

    Mientras que los arrays indexados usan números para identificar sus elementos, los arrays asociativos utilizan claves con nombre (strings). Esto los convierte en una estructura de datos mucho más descriptiva y legible, similar a un diccionario o un mapa. En lugar de acceder a un elemento por su posición, lo hacemos a través de una clave que describe el significado del valor que contiene.

    Este tipo de array es perfecto para representar una entidad única con múltiples propiedades, como los datos de un usuario (con claves como 'nombre', 'email', 'edad') o la configuración de un producto. La relación clave => valor hace que el código sea autoexplicativo, ya que no necesitamos recordar qué significa el índice 2; simplemente accedemos al valor asociado a la clave 'email'. Esta claridad es su principal ventaja y los convierte en una de las estructuras más utilizadas en el desarrollo con PHP.

    <?php

// ----------------------------------------------------
// 1. CREACIÓN DE UN ARRAY ASOCIATIVO
// ----------------------------------------------------
// Se usan claves con nombre (strings) para identificar cada valor.
// Es ideal para representar una entidad única, como un usuario.
$usuario = [
    'nombre' => 'Ana García',
    'email' => 'ana.garcia@email.com',
    'edad' => 28,
    'activo' => true
];

// Mostramos el contenido para ver su estructura clave => valor
echo "<strong>Array asociativo inicial:</strong><br>";
print_r($usuario);
echo "<hr>";


// ----------------------------------------------------
// 2. ACCESO A UN ELEMENTO POR SU CLAVE
// ----------------------------------------------------
// En lugar de un índice numérico, usamos la clave de texto.
// Esto hace el código mucho más legible.
echo "<strong>Accediendo a elementos por su clave:</strong><br>";
echo "El email del usuario es: " . $usuario['email'] . "<br>"; // Salida: ana.garcia@email.com
echo "La edad del usuario es: " . $usuario['edad'] . "<br>";   // Salida: 28
echo "<hr>";


// ----------------------------------------------------
// 3. MODIFICAR UN VALOR
// ----------------------------------------------------
// Se accede al elemento por su clave y se le asigna un nuevo valor.
$usuario['edad'] = 29; // Ana ha cumplido años

echo "<strong>Array con la edad modificada:</strong><br>";
print_r($usuario);
echo "<hr>";


// ----------------------------------------------------
// 4. AÑADIR UN NUEVO PAR CLAVE => VALOR
// ----------------------------------------------------
// Simplemente definimos una nueva clave y le asignamos un valor.
$usuario['ciudad'] = 'Valencia';

echo "<strong>Array con un nuevo elemento añadido:</strong><br>";
print_r($usuario);
echo "<hr>";


// ----------------------------------------------------
// 5. RECORRER LA COLECCIÓN COMPLETA (BUCLE FOREACH)
// ----------------------------------------------------
// El bucle 'foreach' es la forma perfecta de recorrer arrays asociativos,
// ya que nos da acceso tanto a la clave como al valor en cada iteración.
echo "<strong>Recorriendo el array con un bucle foreach:</strong><br>";
foreach ($usuario as $clave => $valor) {
    // Usamos ucfirst() para poner la primera letra de la clave en mayúscula
    echo ucfirst($clave) . ": " . $valor . "<br>";
}

?>

    Arrays Multidimensionales

    Un array multidimensional es, sencillamente, un array que contiene otros arrays como valores. Esta capacidad de anidamiento nos permite crear estructuras de datos complejas y jerárquicas, como tablas, matrices o árboles.

    Por ejemplo, una lista de usuarios, donde cada usuario es a su vez un array asociativo con sus propios datos, sería un array multidimensional. Para acceder a un valor específico dentro de esta estructura, necesitaríamos encadenar los accesos, indicando primero la clave o índice del array exterior y luego la clave o índice del array interior. Son la herramienta perfecta para manejar conjuntos de datos estructurados, como los resultados de una consulta a una base de datos que devuelve múltiples filas, cada una con varias columnas.

    <?php

// ----------------------------------------------------
// 1. CREACIÓN DE UN ARRAY MULTIDIMENSIONAL
// ----------------------------------------------------
// El ejemplo más común es una lista de usuarios (un array indexado)
// donde cada usuario es, a su vez, un array asociativo con sus datos.
// Esto simula perfectamente el resultado de una consulta a una base de datos.
$usuarios = [
    [ // Índice 0
        'id'     => 1,
        'nombre' => 'Ana García',
        'email'  => 'ana.garcia@email.com'
    ],
    [ // Índice 1
        'id'     => 2,
        'nombre' => 'Luis Soler',
        'email'  => 'luis.soler@email.com'
    ],
    [ // Índice 2
        'id'     => 3,
        'nombre' => 'Eva Parra',
        'email'  => 'eva.parra@email.com'
    ]
];

// Mostramos la estructura completa. La etiqueta <pre> ayuda a que la salida sea legible.
echo "<strong>Array multidimensional inicial:</strong><br>";
echo "<pre>";
print_r($usuarios);
echo "</pre>";
echo "<hr>";


// ----------------------------------------------------
// 2. ACCESO A UN VALOR ESPECÍFICO
// ----------------------------------------------------
// Se "encadenan" los accesos: primero el índice del array exterior
// y luego la clave del array interior.

// Por ejemplo, para obtener el nombre del segundo usuario (índice 1):
$nombre_segundo_usuario = $usuarios[1]['nombre'];

echo "<strong>Accediendo a un dato específico:</strong><br>";
echo "El nombre del segundo usuario es: " . $nombre_segundo_usuario; // Salida: Luis Soler
echo "<hr>";


// ----------------------------------------------------
// 3. MODIFICAR UN VALOR
// ----------------------------------------------------
// Se accede de la misma forma encadenada para modificarlo.
$usuarios[0]['email'] = 'ana.garcia@nuevodominio.com';

echo "<strong>Array con el email del primer usuario modificado:</strong><br>";
echo "<pre>";
print_r($usuarios);
echo "</pre>";
echo "<hr>";


// ----------------------------------------------------
// 4. RECORRER LA ESTRUCTURA COMPLETA
// ----------------------------------------------------
// La forma más común es usar un bucle foreach para recorrer el array exterior (las filas)
// y luego acceder a los datos de cada array interior por su clave.
echo "<strong>Recorriendo el array para mostrar los datos en una tabla:</strong><br>";

echo "<table border='1' cellpadding='5'>";
// Cabecera de la tabla
echo "<tr><th>ID</th><th>Nombre</th><th>Email</th></tr>";

// Cuerpo de la tabla
foreach ($usuarios as $usuario) {
    echo "<tr>";
    echo "<td>" . $usuario['id'] . "</td>";
    echo "<td>" . $usuario['nombre'] . "</td>";
    echo "<td>" . $usuario['email'] . "</td>";
    echo "</tr>";
}

echo "</table>";

?>

    Comparación de Arrays

    En PHP, es posible comparar dos arrays para determinar si son iguales. Para ello, se utilizan operadores de comparación específicos que van más allá de una simple comprobación de valores.

    El operador de igualdad (==) considera que dos arrays son iguales si ambos tienen el mismo conjunto de pares clave => valor, sin importar el orden en que estos pares fueron definidos. Por otro lado, el operador de identidad (===) es mucho más estricto: no solo exige que los pares clave => valor sean los mismos, sino que también requiere que el orden de los elementos y los tipos de datos de los valores sean idénticos. Entender la diferencia entre estos dos operadores es fundamental para evitar errores lógicos al verificar si dos colecciones de datos son verdaderamente equivalentes.

    Veamos una tabla resumen de los comparadores de arrays:

    Operador Nombre true si...
    $a == $b Igualdad $a y $b tienen los mismos pares clave => valor, sin importar el orden.
    $a === $b Identidad $a y $b tienen los mismos pares clave => valor, en el mismo orden y los valores son del mismo tipo.
    $a != $b Desigualdad $a no es igual (==) a $b.
    $a <> $b Desigualdad $a no es igual (==) a $b.
    $a !== $b No Identidad $a no es idéntico (===) a $b.
    $a + $b Unión No es un comparador. Crea un nuevo array añadiendo los elementos de $b a $a solo si las claves de $b no existen en $a. No sobreescribe.
