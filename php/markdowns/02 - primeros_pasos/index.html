    Primeros pasos

    Una vez comprendido el papel de PHP en el desarrollo web, es momento de sumergirse en la escritura del código. Como en cualquier lenguaje de programación, comenzar con un simple "¡Hola, Mundo!" es la forma ideal de familiarizarse con la sintaxis básica y cómo PHP se integra en una página web.

    Para que el servidor web reconozca y procese el código PHP, este debe estar encapsulado dentro de etiquetas especiales. El estándar es <?php para abrir el bloque de código y ?> para cerrarlo. Todo lo que esté fuera de estas etiquetas será interpretado como HTML plano.

    Para mostrar texto en la pantalla, PHP utiliza la instrucción echo (o print, aunque echo es más común y ligeramente más eficiente). Cada sentencia en PHP debe finalizar con un punto y coma (;), indicando el fin de la instrucción.

    Aquí tienes el ejemplo básico de un archivo PHP que muestra "¡Hola, Mundo!" y su correspondiente en Java:

    <!DOCTYPE html>
<html lang="es">
    <head>
        <meta charset="UTF-8">
        <meta name="viewport" content="width=device-width, initial-scale=1.0">
        <title>Mi Primer PHP</title>
    </head>
    <body>

        <h1>Mensaje desde PHP:</h1>

        <?php
            // Esto es un comentario de una línea en PHP
            echo "¡Hola, Mundo desde PHP!";
            /*
                Este es un comentario
                de varias líneas en PHP.
                Ignora todo el texto aquí dentro.
            */
        ?>

        <p>Este es contenido HTML que no es procesado por PHP.</p>

    </body>
</html>

    public class HelloWorld {
    public static void main(String[] args) {
        System.out.println("Hello, World!");
    }
}

    Nota

    A lo largo del contenido de la sección en la que vamos a explicar el código Php, se intentará introducir siempre el mismo contenido de código en Java para facilitar su aprendizaje y se pueda comparar de forma fácil.

    Para ejecutar este archivo, deberás guardarlo con extensión .php (por ejemplo, primer_script.php) dentro del directorio de tu servidor web (como htdocs en XAMPP o www en WampServer) y luego acceder a él a través de tu navegador (por ejemplo, http://localhost/primer_script.php).

    Declaración y Uso de Variables

    Las variables son contenedores que permiten almacenar información temporalmente en la memoria durante la ejecución de un script. En PHP, todas las variables comienzan con el símbolo del dólar ($), seguido de su nombre. Los nombres de las variables deben comenzar con una letra o un guion bajo, y pueden contener letras, números o guiones bajos. Son sensibles a mayúsculas y minúsculas (es decir, $miVariable es diferente de $mivariable).

    PHP es un lenguaje de tipado dinámico, lo que significa que no es necesario declarar explícitamente el tipo de dato que almacenará una variable (como texto, número entero o decimal). PHP lo determina automáticamente en tiempo de ejecución.

    Aquí tienes algunos ejemplos de declaración y uso de variables:

    <?php
    // Variables de texto (cadenas de caracteres o strings)
    $saludo = "¡Hola, programadores!";
    $nombre = "Juan Pérez";

    // Variables numéricas
    $edad = 30; // Entero (integer)
    $precio = 19.99; // Decimal (float o double)

    // Variable booleana (verdadero/falso)
    $esActivo = true; // o false

    // Mostrar el contenido de las variables
    echo $saludo . "<br>"; // El punto (.) se usa para concatenar cadenas
    echo "Mi nombre es " . $nombre . " y tengo " . $edad . " años.<br>";
    echo "El precio del producto es: $" . $precio . "<br>";

    // Operaciones básicas con variables
    $numero1 = 10;
    $numero2 = 5;
    $suma = $numero1 + $numero2;
    $resta = $numero1 - $numero2;
    $multiplicacion = $numero1 * $numero2;
    $division = $numero1 / $numero2;

    echo "Suma: " . $suma . "<br>";
    echo "Resta: " . $resta . "<br>";
    echo "Multiplicación: " . $multiplicacion . "<br>";
    echo "División: " . $division . "<br>";
?>

    public class VariablesDemo {
    public static void main(String[] args) {
        // Variables de texto (cadenas de caracteres o strings)
        String saludo = "¡Hola, programadores!";
        String nombre = "Juan Pérez";

        // Variables numéricas
        int edad = 30;              // Entero (integer)
        double precio = 19.99;      // Decimal (double)

        // Variable booleana (verdadero/falso)
        boolean esActivo = true;    // o false

        // Mostrar el contenido de las variables
        System.out.println(saludo);
        System.out.println("Mi nombre es " + nombre + " y tengo " + edad + " años.");
        System.out.println("El precio del producto es: $" + precio);

        // Operaciones básicas con variables
        int numero1 = 10;
        int numero2 = 5;
        int suma = numero1 + numero2;
        int resta = numero1 - numero2;
        int multiplicacion = numero1 * numero2;
        double division = (double) numero1 / numero2; // Conversión a double para resultado decimal

        System.out.println("Suma: " + suma);
        System.out.println("Resta: " + resta);
        System.out.println("Multiplicación: " + multiplicacion);
        System.out.println("División: " + division);
    }
}

    Para dominar el uso de las variables en PHP, es fundamental comprender varias características que definen su sintaxis y comportamiento.

    La distinción más inmediata es que cada variable en PHP debe comenzar con el símbolo del dólar ($), una convención obligatoria que las diferencia de otros identificadores en el código.

    Cuando el objetivo es combinar texto literal con el valor que contiene una variable para generar una salida cohesiva, como un mensaje en pantalla, se emplea el operador de concatenación (.), permitiendo la unión fluida de diferentes tipos de contenido.

    Una particularidad importante de PHP es su tipado dinámico, lo que significa que no se requiere una declaración explícita del tipo de dato (ya sea texto, número entero o decimal) que una variable contendrá. El propio lenguaje se encarga de inferir y gestionar el tipo de dato en el momento de la asignación. Si bien esta flexibilidad simplifica el proceso de codificación inicial, es crucial para el desarrollador mantener una conciencia clara del tipo de dato con el que está trabajando para prevenir errores lógicos inesperados.

    Finalmente, la naturaleza de las variables en PHP permite su reasignación; el valor almacenado en una variable puede ser modificado y actualizado en cualquier punto del script, facilitando la adaptación del programa a datos cambiantes durante su ejecución.

    Con estos conceptos básicos bien asentados, ya se está en capacidad de empezar a escribir scripts PHP sencillos, mostrando información y manipulando datos de forma básica. El siguiente paso natural en este recorrido de aprendizaje es explorar en mayor profundidad los diferentes tipos de datos y las estructuras de control, elementos esenciales para crear lógica y comportamiento más complejos en las aplicaciones.

    Tipos de Datos en PHP: Categorizando la Información

    En programación, cada pieza de información que manejamos —ya sea un nombre, una edad, un precio o una condición de verdadero/falso— tiene una naturaleza específica. Los tipos de datos definen esta naturaleza, indicando el tipo de valores que una variable puede almacenar y las operaciones que se pueden realizar sobre ellos. Aunque PHP es de tipado dinámico (lo que significa que no necesitas declarar el tipo de dato de una variable explícitamente), comprenderlos es fundamental para escribir código robusto y predecible.

    PHP clasifica los tipos de datos en varias categorías, las cuales veremos a continuación.

    Tipos Escalares (Valores Únicos)

    Estos tipos de datos representan un único valor y son los más básicos.

    • Integer (Enteros): Representan números enteros, positivos o negativos, sin parte decimal. Son ideales para contar elementos, IDs o cualquier valor que no requiera precisión decimal.

      <?php
    $edad = 25;        // Un número entero positivo
    $cantidad = -100;  // Un número entero negativo
    $id_usuario = 12345; // Un ID de usuario
?>

      public class VariablesEnteras {
    public static void main(String[] args) {
        int edad = 25;          // Un número entero positivo
        int cantidad = -100;    // Un número entero negativo
        int idUsuario = 12345;  // Un ID de usuario
    }
}

    • Float (Números de coma flotante / Decimales): Utilizados para representar números con parte decimal o números muy grandes/pequeños. También se les conoce como "doubles".

      <?php
    $precio = 99.99;        // Un número decimal
    $temperatura = 23.5;    // Un valor con punto decimal
    $pi = 3.14159;          // Una constante matemática
?>

      public class VariablesDecimales {
    public static void main(String[] args) {
        double precio = 99.99;         // Un número decimal
        double temperatura = 23.5;     // Un valor con punto decimal
        double pi = 3.14159;           // Una constante matemática
    }
}

    • String (Cadenas de caracteres): Son secuencias de caracteres, utilizadas para almacenar texto. Las cadenas se encierran entre comillas simples (' ') o comillas dobles (" "). Hay diferencias sutiles entre ambas: las comillas dobles permiten la interpolación de variables y el uso de secuencias de escape (como \n para nueva línea), mientras que las simples no.

      <?php
    $nombre = "Carlos";           // Cadena con comillas dobles
    $mensaje = 'Hola, mundo!';    // Cadena con comillas simples
    $direccion = "Calle Falsa 123, \nCiudad Ejemplo"; // Con \n para salto de línea
    $saludo_completo = "Bienvenido, $nombre."; // La variable $nombre se interpola
    $saludo_simple = 'Bienvenido, $nombre.';   // Aquí se muestra "$nombre" literal
?>

      public class VariablesTexto {
    public static void main(String[] args) {
        String nombre = "Carlos";                            // Cadena con comillas dobles
        String mensaje = "Hola, mundo!";                     // Java usa comillas dobles siempre
        String direccion = "Calle Falsa 123,\nCiudad Ejemplo"; // \n para salto de línea

        // En Java no existe interpolación automática de variables en cadenas como en PHP
        String saludoCompleto = "Bienvenido, " + nombre + "."; // Concatenación explícita

        // Mostrar los valores (opcional)
        System.out.println(saludoCompleto);
        System.out.println(saludoSimple);
        System.out.println(direccion);
    }
}

    • Boolean (Booleanos): Representan un valor de verdad, es decir, true (verdadero) o false (falso). Son fundamentales para la lógica condicional y las comparaciones. No distinguen entre mayúsculas y minúsculas (TRUE, False también son válidos, aunque se recomienda usar true y false en minúscula).

      <?php
    $esta_logueado = true;   // El usuario está logueado
    $es_admin = false;       // El usuario no es administrador
    $resultado_comparacion = (10 > 5); // Esto asignará true
?>

      public class VariablesBooleanas {
    public static void main(String[] args) {
        boolean estaLogueado = true;              // El usuario está logueado
        boolean esAdmin = false;                  // El usuario no es administrador
        boolean resultadoComparacion = (10 > 5);  // Esto asignará true

        // Mostrar los valores (opcional)
        System.out.println("¿Está logueado? " + estaLogueado);
        System.out.println("¿Es administrador? " + esAdmin);
        System.out.println("¿10 es mayor que 5? " + resultadoComparacion);
    }
}

    Tipos Compuestos (Colecciones de Valores)

    Estos tipos pueden almacenar múltiples valores o colecciones de datos.

    • Array (Arreglos / Matrices): Un array es una colección ordenada de valores. Cada valor en un array se conoce como un "elemento", y cada elemento tiene una "clave" (o índice) asociada, que puede ser numérica (automática) o una cadena de texto (asociativa). Los arrays son extremadamente versátiles y se usan para agrupar datos relacionados.

      <?php
    // Array indexado numéricamente
    $frutas = ["Manzana", "Naranja", "Pera"];
    echo $frutas[0]; // Muestra "Manzana"

    // Array asociativo (clave-valor)
    $persona = [
        "nombre" => "Ana",
        "edad" => 28,
        "ciudad" => "Madrid"
    ];
    echo $persona["nombre"]; // Muestra "Ana"

    // Acceder a elementos
    echo "Mi fruta favorita es " . $frutas[1] . ".<br>";
    echo "La persona se llama " . $persona["nombre"] . " y tiene " . $persona["edad"] . " años.<br>";
?>

      import java.util.HashMap;
import java.util.Map;

public class ArraysYMapas {
    public static void main(String[] args) {
        // Array indexado numéricamente
        String[] frutas = {"Manzana", "Naranja", "Pera"};
        System.out.println(frutas[0]);  // Muestra "Manzana"

        // Mapa asociativo (clave-valor)
        Map<String, Object> persona = new HashMap<>();
        persona.put("nombre", "Ana");
        persona.put("edad", 28);
        persona.put("ciudad", "Madrid");

        System.out.println(persona.get("nombre"));  // Muestra "Ana"

        // Acceder a elementos y mostrar
        System.out.println("Mi fruta favorita es " + frutas[1] + ".");
        System.out.println("La persona se llama " + persona.get("nombre") + " y tiene " + persona.get("edad") + " años.");
    }
}

    • Object (Objetos): Representan instancias de clases. En la programación orientada a objetos (POO), los objetos encapsulan datos (propiedades) y comportamientos (métodos). Este es un tema avanzado que se explorará en secciones futuras. Lo veremos en más detalle en sus ección.

    Tipos Especiales

    • NULL: Representa una variable que no tiene valor asignado. Una variable es NULL si:

      • Se le ha asignado explícitamente el valor NULL.
      • No se le ha asignado ningún valor todavía.
      • Ha sido unset() (destruida).
      <?php
    $variable_nula = NULL;
    $otra_variable; // Si no se asigna, su valor inicial es NULL
    unset($frutas); // $frutas ahora es NULL
?>

      public class VariablesNulas {
    public static void main(String[] args) {
        // En Java, las variables de referencia pueden ser null
        String variableNula = null;

        // Las variables deben ser inicializadas antes de usarse,
        // no existe "variable sin asignar" como en PHP,
        // así que declarar sin asignar no es válido y da error de compilación.

        String otraVariable; // Declaración, pero sin inicializar -> no se puede usar aún

        // Para simular "unset" (eliminar variable), simplemente asignamos null
        String[] frutas = {"Manzana", "Naranja", "Pera"};
        frutas = null;  // Ahora la variable frutas referencia a null
    }
}

    • Resource (Recurso): Es un tipo de dato especial que representa un manejador o una referencia externa a un recurso externo (como una conexión a una base de datos, un archivo abierto o una imagen). Se crean y gestionan mediante funciones especiales de PHP y no se manipulan directamente.

      <?php
    // Ejemplo de recurso (conexión a una base de datos, no se muestra el resultado directamente)
    // $link_conexion = mysqli_connect("localhost", "usuario", "password", "mi_bd");
    // echo get_resource_type($link_conexion); // Mostrará "mysql link" o similar
?>

    Comprender estos tipos de datos es esencial para manejar la información de manera efectiva en PHP, asegurando que las operaciones se realicen correctamente y que el código sea legible y eficiente. El conocimiento de estos fundamentos te permitirá construir estructuras de datos más complejas y lógicas de programa avanzadas.

    Asignación por copia y por referencia

    En PHP, la asignación de variables se puede hacer de dos maneras: por copia (el comportamiento por defecto) o por referencia (usando el símbolo &). Veamos como funciona cada una de estas aproximaciones.

    Asignación por copia

    Esta es la forma estándar y más común. Cuando asignas una variable a otra, PHP crea una copia independiente del valor. Las dos variables no tienen ninguna conexión entre ellas después de la asignación.

    Es como tener una nota en un papel ($a). Al hacer la asignación, coges un papel nuevo ($b) y escribes el mismo valor. A partir de ese momento, tienes dos papeles distintos; lo que hagas en uno no afecta al otro.

    <?php 
    // 1. Asignamos un valor a la variable $a
    $a = 10;

    // 2. Hacemos una copia de su valor en $b
    $b = $a;

    // 3. Modificamos solo la variable $b
    $b = 20;

    // 4. Comprobamos los valores
    echo "El valor de \$a es: " . $a; // Salida: El valor de $a es: 10
    echo "<br>";
    echo "El valor de \$b es: " . $b; // Salida: El valor de $b es: 20
?>

    Asignación por Referencia

    La asignación por referencia no copia el valor. En su lugar, crea un "alias" o un segundo nombre que apunta al mismo dato en memoria. Ambas variables están vinculadas; si cambias una, la otra también cambia.

    Para crear una referencia, se utiliza el símbolo & (ampersand) antes de la variable que se va a referenciar.

    Es como ponerle un apodo a una persona. Si "Roberto" ($x) y "Beto" (&$x) son la misma persona, cualquier cosa que le ocurra a "Beto" también le habrá ocurrido a "Roberto".

    <?php
    // 1. Asignamos un valor a la variable $x
    $x = 100;

    // 2. Creamos una referencia de $x en $y
    $y = &$x;

    // 3. Modificamos solo la variable $y
    $y = 200;

    // 4. Comprobamos los valores
    echo "El valor de \$x es: " . $x; // Salida: El valor de $x es: 200
    echo "<br>";
    echo "El valor de \$y es: " . $y; // Salida: El valor de $y es: 200
?>

    Variables predefinidas

    PHP ofrece un gran número de variables predefinidas que están siempre disponibles en cualquier parte de tus scripts. La mayoría de estas son las "superglobales", que se pueden acceder desde cualquier ámbito (dentro de una función, clase o fichero) sin necesidad de hacer nada especial. Estas variables proporcionan información sobre el entorno del servidor y los datos de la petición del usuario.

    $_SERVER

    Es un array que contiene una gran cantidad de información sobre las cabeceras, rutas y ubicaciones del script proporcionada por el servidor web. Es extremadamente útil para obtener información del entorno.

    Podemos ver algunas de las claves de la variable $_SERVER:

    Clave Descripción
    REQUEST_METHOD El método HTTP utilizado en la petición (p. ej., 'GET', 'POST').
    REQUEST_URI La URI completa usada para acceder a la página (p. ej., /productos.php?id=10).
    SERVER_NAME El nombre del host del servidor donde se está ejecutando el script (p. ej., www.ejemplo.com).
    REMOTE_ADDR La dirección IP del cliente que está realizando la petición. 
    <?php
    if ($_SERVER['REQUEST_METHOD'] == 'POST') {
        echo "Este formulario ha sido enviado.";
    }
?>

    $_GET

    Es un array asociativo con las variables pasadas al script a través de la URL (query string). Es la información que va después del ?.

    <?php
    echo "Estás buscando el término: " . $_GET['term']; // Salida: Estás buscando el término: libros
    echo "Estás en la página: " . $_GET['page'];       // Salida: Estás en la página: 2
?>

    $_POST

    Es un array asociativo con las variables pasadas al script a través del método HTTP POST, normalmente desde un formulario HTML que tiene method="post".

    <?php
    // Se recomienda comprobar si el dato existe antes de usarlo.
    if (isset($_POST['username'])) {
        echo "El nombre de usuario enviado es: " . $_POST['username'];
    }
?>

    $_FILES

    Es un array asociativo que contiene información sobre los ficheros subidos a través de un formulario con el método POST y enctype="multipart/form-data". Contiene datos como el nombre original del fichero, el tipo, el tamaño y la ubicación temporal en el servidor.

    <?php
    if (isset($_FILES['avatar'])) {
        $nombre_temporal = $_FILES['avatar']['tmp_name'];
        echo "El fichero se ha subido temporalmente a: " . $nombre_temporal;
    }
?>

    $_SESSION

    Es un array asociativo que se usa para persistir datos de un usuario a través de múltiples páginas. Antes de poder usar esta variable, es obligatorio iniciar la sesión con la función session_start(); al principio del script.

    <?php
    // Código de la primera página
    session_start();
    $_SESSION['usuario_id'] = 123;
    echo "Sesión iniciada.";

    // Código de la seguna página

    session_start();
    if (isset($_SESSION['usuario_id'])) {
        echo "El ID de usuario guardado en la sesión es: " . $_SESSION['usuario_id']; // Salida: 123
    }
?>

    $_COOKIE

    Es un array asociativo con las variables pasadas al script a través de HTTP Cookies. Permite leer los datos que han sido previamente almacenados en el navegador del cliente.

    <?php
    // Para leer una cookie llamada 'idioma'
    if (isset($_COOKIE['idioma'])) {
        echo "El idioma seleccionado es: " . $_COOKIE['idioma'];
    }
?>

    $_REQUEST

    Es un array que, por defecto, contiene los datos de $_GET, $_POST y $_COOKIE.

    Nota importante: Se desaconseja encarecidamente el uso de $_REQUEST porque mezcla el origen de los datos, lo que hace el código menos claro y puede introducir vulnerabilidades de seguridad. Es siempre mejor ser explícito y usar $_GET o $_POST según corresponda.

    Constantes

    Una constante es un identificador (un nombre) para un valor simple que, una vez definido, no puede ser modificado ni eliminado durante la ejecución del script. Son útiles para almacenar valores que sabes que no deben cambiar, como datos de configuración o valores matemáticos.

    A diferencia de las variables, el nombre de una constante no empieza con el símbolo $. Por convención, los nombres de las constantes se escriben en mayúsculas.

    Existen dos formas principales de definir una constante en PHP: la función define() y la palabra clave const.

    Usando la función define()

    Esta es la forma tradicional. La función define() acepta dos argumentos principales: el nombre de la constante (como una cadena de texto) y su valor.

    <?php
    define('NOMBRE_SITIO', 'Mi Tienda Online');
    define('MAX_PRODUCTOS', 100);

    echo "Bienvenido a " . NOMBRE_SITIO; // Salida: Bienvenido a Mi Tienda Online
?>

    public static final String NOMBRE_SITIO = "Mi Tienda Online";
public static final int MAX_PRODUCTOS = 100;

public static void main(String[] args) {
    // Mostrar mensaje de bienvenida
    System.out.println("Bienvenido a " + NOMBRE_SITIO); // Salida: Bienvenido a Mi Tienda Online
}

    Usando la palabra clave const

    Esta es la forma más moderna y, en general, preferida por su claridad y rendimiento ligeramente superior.

    <?php
    const PI = 3.14159;
    const ACTIVO = true;

    if (ACTIVO) {
        echo "El valor de PI es: " . PI; // Salida: El valor de PI es: 3.14159
    }
?>

    public static final double PI = 3.14159;
public static final boolean ACTIVO = true;

public static void main(String[] args) {
    if (ACTIVO) {
        System.out.println("El valor de PI es: " + PI); // Salida: El valor de PI es: 3.14159
    }
}

    Mostrar información

    La capacidad de mostrar información al usuario es un pilar fundamental en cualquier aplicación web. En PHP, existen varias funciones y construcciones del lenguaje diseñadas para este propósito, cada una con sus particularidades.

    Echo

    La instrucción echo es la más utilizada para enviar salida al navegador. Puede mostrar una o más cadenas de caracteres separadas por comas. Es ligeramente más rápida que print y no devuelve ningún valor.

    <?php
    echo "Hola, esto es un mensaje de echo.";
    echo "<br>"; // Salto de línea HTML
    echo "Múltiples ", "cadenas ", "con ", "echo.";

    $nombre = "Mundo";
    echo "¡Hola, " . $nombre . "!"; // Concatenación de cadenas
    echo "<br>";
    echo "¡Hola, $nombre!"; // Interpolación de variables con comillas dobles
    ?>

    Print

    Similar a echo, print también se utiliza para mostrar cadenas. Sin embargo, print solo puede aceptar un argumento y devuelve un valor de 1 (siempre exitoso), lo que lo hace útil en algunas expresiones. En la práctica, su uso es menos común que echo para la salida general.

    <?php
    print "Este es un mensaje de print.";
    echo "<br>";

    $resultado = print "Print también puede ser parte de una expresión.";
    echo "<br>";
    echo "El valor de resultado es: " . $resultado; // Mostrará "El valor de resultado es: 1"
?>

    Print_r()

    Esta función es especialmente útil para depuración. Muestra información legible para humanos sobre una variable. Es excelente para inspeccionar el contenido de arrays y objetos, ya que muestra sus estructuras internas.

    <?php
    $frutas = ["Manzana", "Naranja", "Pera"];
    $persona = [
        "nombre" => "Ana",
        "edad" => 28,
        "ciudad" => "Madrid"
    ];

    echo "<pre>"; // Para mantener el formato del array
    print_r($frutas);
    echo "</pre>";

    echo "<pre>";
    print_r($persona);
    echo "</pre>";
?>

    Var_dump()

    Otra función de depuración muy potente. var_dump() muestra información estructurada sobre una o más expresiones, incluyendo su tipo y valor. Para arrays y objetos, es aún más detallada que print_r(), mostrando el tipo de dato y la longitud de cada elemento.

    <?php
    $texto = "Hola";
    $numero = 123;
    $decimal = 10.5;
    $booleano = true;
    $nulo = NULL;
    $mi_array = [1, "dos", true];

    var_dump($texto);
    var_dump($numero);
    var_dump($decimal);
    var_dump($booleano);
    var_dump($nulo);
    var_dump($mi_array);
?>

    Comentarios: Dejando Notas en el Código ✍️

    Los comentarios son anotaciones dentro del código fuente que son completamente ignoradas por el intérprete de PHP. Su único propósito es ser leídos por los seres humanos. Escribir buenos comentarios es una práctica esencial para crear código legible y mantenible, tanto para otros programadores que puedan trabajar en el proyecto como para tu "yo" del futuro.

    Los comentarios no sirven para explicar qué hace el código (el código en sí mismo debería ser lo más claro posible), sino para explicar el porqué. Se utilizan para aclarar la intención detrás de una pieza de lógica compleja, para dejar advertencias sobre posibles efectos secundarios, o para documentar decisiones de diseño. También son una herramienta muy útil para desactivar temporalmente una línea o un bloque de código durante la depuración, sin necesidad de borrarlo.

    PHP soporta varios estilos de comentarios, heredados de otros lenguajes.

    Comentarios de una Sola Línea

    Se utilizan para notas cortas y concisas. Todo lo que se escriba desde el inicio del comentario hasta el final de la línea será ignorado. Existen dos formas de hacerlo:

    • Usando una doble barra inclinada // (estilo C++).
    • Usando una almohadilla # (estilo de scripts de shell).

    El uso de // es, con diferencia, el más extendido y recomendado en la comunidad PHP.

    <?php
    // Este es un comentario de una sola línea.
    // La siguiente línea calcula el total de la compra.
    $total = $precio_base * 1.21; // Añadimos el 21% de IVA.

    # Este es otro estilo de comentario, menos común.
    echo "El total es: " . $total;
?>

    Comentarios Multilínea (Bloques de Comentario)

    Cuando se necesita una explicación más larga que abarca varias líneas, se utilizan los bloques de comentario. Este tipo de comentario comienza con /* y termina con */. Todo el texto contenido entre estas dos marcas será ignorado, sin importar cuántas líneas ocupe.

    <?php
    /*
    Este es un bloque de comentario multilínea.
    Aquí podemos explicar con más detalle el funcionamiento de la siguiente función.
    La función toma dos números y devuelve su suma.
    */
    function sumar($a, $b) {
        return $a + $b;
    }

    // Ejemplo de cómo "comentar" un bloque de código para desactivarlo:
    /*
    echo "Esta línea está desactivada temporalmente.";
    $resultado = 10 / 0; // Esto también está desactivado y no causará un error.
    */
?>

    El Estándar PHPDoc

    Existe un tipo especial de bloque de comentario conocido como PHPDoc, que comienza con /** (una barra y dos asteriscos). Estos comentarios tienen un formato estructurado y son utilizados por los IDEs y otras herramientas para entender y documentar el código automáticamente. Permiten describir qué hace una función, qué parámetros acepta (@param) y qué devuelve (@return), mejorando el autocompletado y el análisis estático del código.

    <?php
    /**
     * Suma dos números enteros.
     *
     * @param int $a El primer número.
     * @param int $b El segundo número.
     * @return int La suma de $a y $b.
     */
    function sumar_documentado($a, $b) {
        return $a + $b;
    }
?>

    Operadores

    Los operadores son símbolos especiales que le indican al intérprete de PHP que debe realizar una operación específica, ya sea matemática, lógica o de comparación. Son los "verbos" de nuestro código, los elementos que nos permiten manipular variables, combinar valores y, en definitiva, crear expresiones para tomar decisiones.

    Un operador actúa sobre uno o más valores, conocidos como operandos. Por ejemplo, en la expresión $a + $b, el operador es + y los operandos son $a y $b. Dominar el uso de los operadores es fundamental para escribir cualquier tipo de lógica, desde simples cálculos hasta complejas validaciones de datos.

    Para facilitar su estudio, los operadores en PHP se agrupan en diferentes categorías según la función que realizan. A continuación, se presenta una tabla resumen con los operadores más importantes que utilizarás en tu día a día como desarrollador.

    Operador Nombre / Descripción Ejemplo
    Operadores Aritméticos Para realizar operaciones matemáticas
    + Adición $a + $b
    - Sustracción $a - $b
    * Multiplicación $a * $b
    / División $a / $b
    % Módulo (Resto de la división) $a % $b
    ** Exponenciación $a ** $b
    Operadores de Asignación Para asignar valores a variables
    = Asignación simple $a = 5;
    += Adición y asignación $a += 5; (equivale a $a = $a + 5;)
    -= Sustracción y asignación $a -= 5; (equivale a $a = $a - 5;)
    *= Multiplicación y asignación $a *= 5; (equivale a $a = $a * 5;)
    .= Concatenación y asignación $a .= "mundo"; (equivale a $a = $a . "mundo";)
    Operadores de Comparación Para comparar dos valores
    == Igual true si $a y $b tienen el mismo valor.
    === Idéntico true si $a y $b tienen el mismo valor y son del mismo tipo.
    != o <> Diferente true si $a no es igual a $b.
    !== No idéntico true si $a no es igual a $b o no son del mismo tipo.
    < Menor que true si $a es estrictamente menor que $b.
    > Mayor que true si $a es estrictamente mayor que $b.
    <= Menor o igual que true si $a es menor o igual que $b.
    >= Mayor o igual que true si $a es mayor o igual que $b.
    <=> Nave espacial (Spaceship) Devuelve -1, 0 o 1 si $a es menor, igual o mayor que $b.
    Operadores Lógicos Para combinar expresiones condicionales
    and o && Y (And) true si tanto $a como $b son true. (&& tiene mayor precedencia)
    or o || O (Or) true si $a o $b (o ambos) son true. (|| tiene mayor precedencia)
    xor O Exclusivo (Xor) true si $a o $b es true, pero no ambos.
    ! No (Not) Invierte el valor booleano de la expresión. !true es false.
    Operadores a Nivel de Bit Operan sobre los bits de los números enteros
    & And a nivel de bit Los bits que están activos en ambos operandos se activan.
    | Or a nivel de bit Los bits que están activos en cualquiera de los operandos se activan.
    ^ Xor a nivel de bit Los bits que están activos en uno de los operandos, pero no en ambos, se activan.
    ~ Not a nivel de bit Invierte todos los bits del operando.
    << Desplazamiento a la izquierda Desplaza los bits de $a a la izquierda $b pasos.
    >> Desplazamiento a la derecha Desplaza los bits de $a a la derecha $b pasos.
    Otros Operadores De incremento, concatenación, control, etc.
    ++ Incremento $a++ (post-incremento) o ++$a (pre-incremento).
    -- Decremento $a-- (post-decremento) o --$a (pre-decremento).
    . Concatenación Une dos strings. "Hola" . " " . "Mundo"
    ?: Ternario (condición) ? 'valor si true' : 'valor si false';
    ?? Fusión de null (Null Coalesce) $variable_o_valor_defecto = $valor_puede_ser_null ?? 'defecto';
